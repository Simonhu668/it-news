Claude Code“不再询问”把口令写进项目文件：1,122 份公开 GitHub 副本含真实凭据

Apiiro 11 月 5 日发布研究（The Hacker News 11 月 7 日报道）：Claude Code 的“允许且不再询问”选项会把含口令或密钥的完整命令以明文保存到项目文件 .claude/settings.local.json；公开 GitHub 上 104,185 份该文件中有 1,122 份含真实凭据，共 1,379 个不同凭据，包括 379 个数据库口令、43 个 SSH 登录、42 个代码托管与包管理令牌、23 个 AWS 密钥，涉及 63 个组织；其中 215 份未被 gitleaks 与 TruffleHog 检出；删除文件无法消除已提交到 git 历史与分支副本中的泄露，须先轮换全部凭据再清理。

推荐理由：与开发工具凭据管理与代码仓库安全工作有关。值得带走的是“智能体工具的本地配置文件也要当作凭据载体来管”的做法：在组织内搜索 .claude/settings.local.json 与 .claude/settings.json（含 git 历史），先轮换再清理，并把凭据改成环境变量引用。适用条件：使用 Claude Code 或其他 AI 编程助手并把代码提交到 GitHub 的组织；该问题是 Claude Code 的默认行为，16 款同类工具中仅其被确认会把完整命令写入项目文件。
