Power Platform 10–11 月更新：开发者计划环境 11 月 15 日起停建，多项功能 11 月 30 日退役

官方依据：微软 2026 年 10–11 月 Power Platform 功能更新，经 WindowsForum 2026 年 11 月 10 日转述｜适用产品及版本：Power Apps、Power Automate、Dataverse…

windowsforum·媒体报道Microsoft 365近期需计划🔵 变更通知收录 11-11 18:30

正文 · AI 翻译

微软 2026 年 10–11 月 Power Platform 功能更新汇总了 Power Platform 社区大会（10 月 27–29 日）前后发布的内容，包括画布应用的新式控件、与 Dataverse 绑定的 AI 功能、桌面流的流程图设计器，以及面向管理员的新监控与治理工具。大部分内容标注为公开预览，文章提醒应先评估再推广，不宜直接用于生产。

最先核查的是开发者计划的变化。微软的文章称可以在现有环境中试用新功能，或"使用开发者计划免费开始"。但微软官方弃用页面写明，自 2026 年 11 月 15 日起，注册 Power Apps 开发者计划不再创建开发者环境，用户也无法再从 Power Apps、Power Platform 管理中心、PowerShell 或 Power Platform CLI 创建新的非托管开发者环境。同一天，Release Planner 退役，Dataverse for Teams 环境的创建也将终止。文章建议：如果计划搭建个人沙箱来测试下述预览功能，在 11 月 15 日前完成，或与管理员沟通改用托管环境。

Power Apps 方面，新式附件控件进入公开预览：经典附件控件只能在表单内使用，新控件可在表单内或画布上独立使用，支持多文件选择与图片缩略图、文件校验、网页端拖放、最大文件数与大小、接受的文件类型、多文件行为、样式与文件事件设置，预览期间支持 SharePoint 列表附件与 Dataverse 附件场景，移动端使用设备自带的文件选择器。微软还点名了另外四个新控件：头像组、人员、指标卡与卡片库；导航、面包屑、筛选、折叠面板与轮播图等控件"目标在 2026 年底前推出"，文章提醒这是目标而非承诺，附件控件的正式可用工作也在进行中，生产发布不要围绕这些日期排计划。现代数据网格新增分页：滚动时自动加载更多记录，或按设定页大小显示编号页；搜索可针对已加载记录或使用制作者自己的数据源筛选公式，排序在数据源支持时可下推。现有应用不受影响，分页属性默认为无，制作者开启后才生效。SharePoint 自定义表单改用响应式多列布局起步；现代"从数据创建应用"模板扩展到全部从数据创建应用的流程。

Dataverse 掩码值揭示功能面向注重安全的制作者：Dataverse.Unmask Power Fx 函数可让画布应用请求已设防的 Dataverse 列的未掩码值，常规视图保持掩码，另设明确的"揭示"操作。它不绕过安全机制——Dataverse 仍执行表、记录与列权限，包括读取未掩码值的权限；一次只返回一个列值；不改动存储的记录，不移除掩码规则，也不在应用其他位置取消掩码。预览于 10 月启动，现有应用不会自动出现揭示按钮，须由制作者添加。

AI 功能方面，Work IQ 中的业务应用进入公开预览：用户可通过自然语言对话查找并处理模型驱动 Power Apps 中的数据，无需打开应用；微软的示例是询问哪些项目被阻塞，再复核并确认一条项目记录的更新。微软称其使用应用现有视图、表单与 Dataverse 数据，遵守用户权限并应用受支持的业务规则，用户在提交前复核并明确确认每项更改。文章提醒，"受支持的业务规则"值得留意：如果应用依赖客户端逻辑，须测试该逻辑在对话发起的更改中是否仍会执行。数据网格中的 AI 行摘要进入公开预览：用户可直接在画布应用的现代数据网格中为符合条件的 Dataverse 行生成简短 AI 摘要，设置分两步——把网格连接到已配置行摘要的 Dataverse 表，再把 ShowAIRowSummary 设为 true；默认关闭，预览自 2026 年 10 月 12 日起逐步推广。生成式页面现可调用自定义 API（公开预览）：用户可触发审批订单、重新计算价格或验证交易等服务器端操作，业务逻辑保留在 Dataverse 内；支持全局与表绑定操作和函数；调用以登录用户身份运行并受 Dataverse 安全机制约束。生成式页面的 Application Insights 集成进入公开预览：管理员在 Power Platform 管理中心配置 Application Insights 数据导出后，Power Apps 会自动发送已发布生成式页面的受支持遥测数据，涵盖页面加载性能、未处理错误、数据操作与导航，制作者无需添加遥测调用、安装 SDK 或填写连接字符串。GitHub 登录的 Agent 辅助画布编辑进入公开预览：制作者可用 GitHub 登录，获得一个在 Power Apps Studio 中并肩编辑的 AI Agent，使用现有应用、数据源、连接器与治理设置；微软称无需重建或迁移。管理员须先在 Power Platform 管理中心开启租户设置。文章提醒注意计费：该功能使用 GitHub 登录并通过 GitHub 计费，微软另有页面说明用量、数据处理与计费细节，财务与采购应在全租户启用前阅读。

Power Automate 桌面流方面，可复用的桌面流模板：制作者可把错误处理、日志记录与报告等常见模式保存为模板，从头创建或把现有桌面流另存为独立模板，编辑、测试、调试并发布后，他人可从已发布的模板新建流程；从模板创建的流程是独立副本，更新模板只影响之后创建的流程，已存在的流程不受影响——这有利于稳定，但模板的修复不会到达用旧版模板建的流程。桌面流的计划触发器进入公开预览：以往按计划运行桌面流须另建云端流触发，现在可在自动化中心直接设置——选择桌面流与执行连接、选择有人值守或无人值守运行模式、设定开始日期时间、重复周期（分钟、小时、天、周或月）与时区；计划视图显示已启用与已禁用的触发器，可按流程或连接引用筛选并列出即将运行的任务，按区域逐步推广。流程图模式进入公开预览：以可视化画布呈现桌面流，操作显示为节点、执行路径显示为连线，可在流程图与序列视图之间切换现有流程；平移、缩放、小地图与布局控件便于处理大型流程；调试时已运行的节点与走过的路径会高亮，状态标记显示哪些操作成功或失败，错误窗格可直接定位到失败节点。

管理与治理方面，Cowork 中的 Power Platform 管理插件进入公开预览：管理员可用自然语言提问，基于租户数据获得关于环境、所有权、策略影响与整体治理状况的答案；微软称这是走向 Agent 优先管理"早期但重要的一步"，文章建议把它当作发现问题与制定计划的工具，在依赖之前先确认它实际能改动什么。路由监控告警进入公开预览：Power Platform for Admins v2 连接器新增"告警触发时"触发器，流程可把 Power Platform 监控告警发送到任何有连接器的目标；微软的示例是把高严重性告警发到运维团队的 Teams 频道，同时为中低严重性告警创建 Azure DevOps 工作项。监控指标导出进入公开预览：监控数据保留 30 天，现在可通过 API 以 OpenTelemetry 格式导出指标并存入自有存储，再进入 Azure Data Explorer、Splunk 或 Datadog 等工具，与业务与运维数据并列；也可为无管理中心访问权限的同事制作仪表板。

须排入计划的退役事项（微软弃用页面所列）：2026 年 11 月 30 日，Power Automate 的"Describe it to design it"面向全部客户退役；2026 年 11 月 30 日之后，模型驱动应用中的记录级共存功能不再提供；自 2026 年 11 月 15 日起无法创建新的 Dataverse for Teams 环境。

文章最后按角色给出优先事项：画布制作者先在测试应用中试用新式附件与数据网格分页；Dataverse 与安全负责人先检查列安全配置文件再添加 Dataverse.Unmask 揭示按钮；RPA 团队在所在区域可用时试用计划触发器，并把错误处理模式做成模板；管理员决定 GitHub Agent 租户设置、Work IQ 参与范围与 Application Insights 导出，并在 11 月 15 日前建好开发者沙箱；财务与采购在广泛启用前阅读 GitHub 计费条款。几乎所有内容都标注为预览、逐步推广或面向更晚日期——先在非生产环境测试，待正式可用后再用于生产应用。

原文

Microsoft's combined October/November 2026 Power Platform feature update covers a lot. It rounds up what was announced around Power Platform Community Conference: new modern controls for canvas apps, AI features tied to Dataverse, a flowchart designer for desktop flows, and new monitoring and governance tools for admins. Most of it is labelled public preview, so treat it as something to evaluate rather than something to roll out on Monday.

For context, Power Plat Stack listed the conference dates as October 27 to 29: Power Platform Community Conference, MGM Grand, Las Vegas. The update came out shortly before Microsoft Ignite, which the same newsletter places at November 17 to 20.

Check the Developer Plan change first. Microsoft's post says you can try the new features in an existing environment or "get started for free using the Developer plan." The timing matters here. Microsoft's own deprecations page says that starting November 15, 2026, signing up for the Power Apps Developer Plan no longer creates a developer environment, and that users can't create new unmanaged developer environments from Power Apps, the Power Platform admin center, PowerShell, or the Power Platform CLI. Power Plat Stack also flagged November 15 as the date when the Release Planner retires, Dataverse for Teams creation ends, unmanaged developer environment creation ends. What this means for you: if you were planning to set up a personal sandbox to test the previews below, do it before November 15 or talk to your admins about managed environments. The blog post doesn't mention this.

Power Apps: modern controls. The classic attachments control only worked inside a form. The new modern attachments control works inside forms or on its own on a canvas, so makers can build custom upload screens. It supports selecting multiple files, with image thumbnails; file validation, plus drag-and-drop on the web; settings for maximum file count, maximum file size, accepted file types, multi-file behaviour, styling and file events; SharePoint list attachments and Dataverse attachment scenarios during preview; the device's own file picker on mobile. Microsoft named four more controls: Avatar group, Persona, Metrics card, Card gallery. The next wave is navigation, breadcrumb, facet, accordion and carousel, "targeted by the end of 2026." That's a target, not a commitment. General availability work for attachments is also listed as ongoing. Don't plan production releases around these dates. The modern data grid now has two ways to load data a bit at a time: load more records automatically as users scroll, or show numbered pages with a page size you set. Search can run against the records already loaded or use the maker's own data-source filtering formula. Sorting can be delegated when the connected source supports it. Existing apps won't change. The pagination property defaults to none, so nothing changes until a maker turns it on. SharePoint custom forms now start from a responsive, multi-column layout instead of the old single-column template. The modern app-from-data template now applies to every app-from-data flow in Power Apps, not only apps built from SharePoint. Revealing masked Dataverse values: the Dataverse.Unmask Power Fx function lets a canvas app request the unmasked value of a secured Dataverse column. It doesn't bypass security. Dataverse still enforces table, record and column permissions, including the read unmasked permission. It returns one column value only. It doesn't change the stored record, remove the masking rule, or unmask the value anywhere else in the app. The preview started in October. Existing apps don't get a reveal button automatically. Makers have to add it.

AI features built on Dataverse. Business apps in Work IQ (public preview): this lets users find and work with data from model-driven Power Apps through natural-language conversation, without opening the app. Microsoft says it uses the app's existing views, forms and Dataverse data, respects user permissions, and applies supported business rules. Users review and explicitly confirm every change before it's submitted. AI row summary in the data grid (public preview): users can generate a short AI summary of an eligible Dataverse row directly from the modern data grid in canvas apps. Setup takes two steps: connect the grid to a Dataverse table that already has row summary configured, then set ShowAIRowSummary to true. It's off by default. The preview rollout began October 12, 2026 and is gradual. Generative pages can call custom APIs (public preview): users can trigger server-side operations such as approving an order, recalculating a price or validating a transaction, while the business logic stays in Dataverse. Works in the generative page designer in Power Apps and through the generative pages plugin for external AI code-generation tools. Supports global and table-bound actions and functions. Calls run as the signed-in user and are subject to Dataverse security. Application Insights for generative pages (public preview): once an admin configures Application Insights data export for the environment in the Power Platform admin center, Power Apps automatically sends supported telemetry for published generative pages, covering page-load performance, unhandled errors, data operations and navigation. GitHub sign-in for agent-assisted canvas editing (public preview): makers can sign in with GitHub and get an AI agent that edits alongside them in Power Apps Studio, using their existing apps, data sources, connectors and governance. Microsoft says nothing needs to be rebuilt or migrated. An admin has to turn on the tenant setting in the Power Platform admin center first. Watch the billing: the feature uses GitHub sign-in and is billed through GitHub. Microsoft points to a separate page for usage, data handling and billing details. Finance and procurement should read that before anyone switches it on for the whole tenant.

Power Automate: desktop flow changes. Reusable desktop flow templates: makers can save common patterns, such as error handling, logging and reporting, as templates. Create a template from scratch, or save an existing desktop flow as a separate template. Edit, test, debug and publish it. Others create new flows from the published template. Flows created from a template are independent copies. Updating a template only affects flows created afterwards, not the ones that already exist. Scheduled triggers for desktop flows (public preview): until now, running a desktop flow on a schedule meant building a separate cloud flow to trigger it. Now you can set it up in Automation center: pick the desktop flow and the execution connection; choose attended or unattended run mode; set the start date, time, recurrence (minutes, hours, days, weeks or months) and time zone. The schedule view shows enabled and disabled triggers, lets you filter by flow or connection reference, and lists upcoming runs. It's rolling out gradually by region. Flowchart mode (public preview): a visual canvas for desktop flows. Actions are shown as nodes and execution paths as the lines connecting them. You can switch an existing flow between flowchart and sequence views. Pan, zoom, a minimap and layout controls help with large flows. While debugging, the nodes that ran and the paths taken are highlighted, status markers show which actions succeeded or failed, and the errors pane can take you straight to the node that failed.

Admin and governance updates. Power Platform admin plugin in Cowork (public preview): admins can ask questions in plain language and get answers based on their tenant's data about environments, ownership, policy impact and overall governance posture. Microsoft calls it "an early but important step" toward agent-first administration. Treat it as a way to find problems and plan fixes, and confirm what it can actually change before relying on it. Routing monitor alerts (public preview): the Power Platform for Admins v2 connector has a new When an alert fires trigger, so a flow can send Power Platform monitor alerts to any destination that has a connector. Microsoft's example sends high-severity alerts to the operations team's Teams channel and creates Azure DevOps work items for medium- and low-severity alerts, all in one flow. Exporting monitor metrics (public preview): Monitor keeps data for 30 days. You can now export its metrics through an API, in OpenTelemetry format, and keep them in your own storage. From there they can go into tools such as Azure Data Explorer, Splunk or Datadog, alongside your business and operational data. You can also build dashboards for colleagues who don't have access to the admin center.

Retirements to plan for. Microsoft's deprecations page lists a few more dates for teams testing these features: On November 30, 2026, Describe it to design it in Power Automate retires for all customers. After November 30, 2026, record-level copresence in model-driven apps won't be available. You can't create new Dataverse for Teams environments starting November 15, 2026.

What to do now: canvas makers should try modern attachments and data grid paging in a test app; Dataverse and security owners should check column security profiles before adding Dataverse.Unmask reveal buttons; RPA teams should try scheduled triggers where they've reached your region, and turn error-handling patterns into templates; admins should decide on the GitHub agent tenant setting, Work IQ participation and Application Insights export, and set up any developer sandboxes before November 15; finance and procurement should read the GitHub billing terms for agent-assisted canvas editing before it's switched on widely. Almost everything here is labelled preview, rolling out gradually, or targeted for a later date. Test it in a non-production environment, and wait for general availability before putting it into production apps.
