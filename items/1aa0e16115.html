Entra 2026 年 11 月 4 日起默认允许普通用户创建 agent blueprint：不关闭等于默认放行

官方依据：微软消息中心 MC1506733｜适用产品：Microsoft Entra ID 的默认用户角色权限｜生效日期：2026 年 11 月初开始全球推广（官方措辞为 11 月 4 日起默认放行），预计 2026 年 11 月下旬完成；…

微软消息中心 MC1506733·官方公告Microsoft 365近期需计划🔵 变更通知收录 10-18 12:30

正文 · AI 翻译

微软 Entra 正在更改谁可以默认创建 agent blueprint。从 2026 年 11 月 4 日起，除非管理员关闭“Users can create agent blueprints”开关，普通用户将能创建新的 agent blueprint。这意味着没有内置或自定义 Entra 角色的用户也能在组织内创建新的 agent blueprint 及其标识。从现在到推广开始前，可以先在租户中设置偏好；若希望限制，需按以下步骤操作。

推广时间：全球范围 2026 年 11 月初开始，预计 2026 年 11 月下旬完成。

影响范围：使用 Microsoft Entra 的组织；没有内置或自定义 Entra 角色的普通用户。

具体变化：普通用户默认可创建 agent blueprint，除非管理员将开关设为“否”。设为“否”后，普通用户无法创建新 agent；拥有管理权限或被分配了 Agent ID Developer 角色的用户仍可创建。现在修改开关，租户不会立即变化，设置在 2026 年 11 月初推广开始时生效。

若允许普通用户创建 agent，什么都不需要做；若要限制：登录 Microsoft Entra 管理中心 → Entra ID → 用户 → 用户设置，在“默认用户角色权限”下找到 Users can create agent blueprints，设为“否”并保存。

本次变化不影响：已有 agent blueprint；已有 blueprint 创建标识；应用或 agent 创建标识；Foundry 或 Security Copilot 等平台的创建要求（如许可与 Azure 订阅）。该设置与“Users can register applications”相互独立，需分别审查。

Office365 IT Pros 等社区意见认为，默认开启与安全优先原则不一致，建议需要管控的组织尽快关闭。

原文

Microsoft Entra is changing who can create agent blueprints by default. Starting November 4, default users will be able to create new agent blueprints unless an administrator turns off Users can create agent blueprints. This means that users without built-in or custom Entra roles will be able to create new agent blueprints in their organization. From now until rollout begins, you can set your tenant preferences to prepare for this rollout.

Rollout schedule - Worldwide: Beginning in early November 2026 and expected to complete by late November 2026.

Impact: Organizations using Microsoft Entra; default users who don't have a built-in or custom Microsoft Entra role. Default users will be able to create agent blueprints unless an administrator turns off Users can create agent blueprints. If you set the toggle to No, default users will not be able to create new agents. Supported administrators and users assigned the Agent ID Developer role can continue to create them. If you change this toggle now, your tenant won't change right away. Your setting takes effect when the rollout begins in early November.

Action: If default users should be allowed to create agents in your organization, no action is required. To restrict creation: 1. Sign in to the Microsoft Entra admin center. 2. Go to Entra ID > Users > User settings. 3. Under Default user role permissions, find Users can create agent blueprints. 4. Set the toggle to No, then save.

This change does not: change or remove existing agent blueprints; change who can create agent identities from existing blueprints; block an app or an agent from creating identities; affect creation requirements within platforms such as Microsoft Foundry or Security Copilot, such as requiring licenses and Azure subscriptions. The new setting is independent of Users can register applications. Review both settings separately.
