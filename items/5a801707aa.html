Copilot Learning Agent 11 月 17 日新增 AI 技能提升页与提示词辅导：个性化用到邮件与会议记录

官方依据：微软 Copilot 博客 2026 年 11 月 17 日公告，经 WindowsForum 同日报道｜适用产品及版本：Microsoft 365 Copilot 内置 Learning Agent；个性化体验 2026 年 1…

windowsforum·媒体报道Microsoft 365行业视野收录 11-22 08:39

正文 · AI 翻译

微软给 Microsoft 365 Copilot 内置的学习体验 Learning Agent 安排了新任务：它过去主要是一个课程目录，现在要在员工工作时提供辅导。微软在 2026 年 11 月 17 日的 Copilot 博客文章中宣布了四项新增内容：专用的 AI 技能提升标签页、精选的 AI Skills Navigator 播放列表、与场景结合的 Copilot 入门提示词，以及引导式提示词辅导。目标是让员工从“知道 Copilot 与 Cowork 能做什么”走向“在日常工作中自信地使用它们”。公告发布于 Microsoft Ignite 期间。

Learning Agent 本身不是新服务，微软称其为今年早些时候推出的“企业学习入口”。一份存档的消息中心公告称，Microsoft 365 Copilot 中的 Learning Agent 将于 2026 年 6 月全面可用，提供个性化学习计划、技能评估与角色扮演场景。据微软称，客户随 Copilot 一同推广了该智能体，反馈集中在三点：与真实工作挂钩的指导、切实的第一步、可以练习的地方；四项新功能分别对应这些需求。微软的部署指引称，在 Microsoft 365 管理中心进入“智能体”页，搜索“Learning (Frontier)”智能体；用户也可自行在 Microsoft Copilot 中打开智能体商店（选择“全部智能体”），搜索“Learning”。本次更新是在已有服务上加功能：如果租户禁用了 Learning Agent，这些内容都不会触达用户。

四项新体验：1. AI 技能提升标签页：微软称其为提升 AI、Microsoft 365 Copilot、Cowork 及微软第一方智能体技能的个性化主页，结合实操指引与学习建议，让用户看到下一步可以尝试什么。用户也可直接向智能体提问，例如“如何用 Copilot 制定项目计划？”或“尝试 Copilot Cowork 之前应该学什么？”2. AI Skills Navigator 播放列表：微软今年早些时候已把 AI Skills Navigator 内容加入 Learning Agent，该功能通过结合分步指引、AI 辅导与动手练习的互动视频体验帮助用户提升技能；新变化是精选播放列表，把课程、模块与视频打包在一起。用户可从技能提升标签页选择播放列表，或在对话中索取。实际好处是模块与视频在 Copilot 对话旁打开，原始问题仍保留在屏幕上，不会堆出一堆浏览器标签页。AI Skills Navigator 内容面向 Microsoft Copilot 用户与 Copilot Chat 用户；任何拥有 Microsoft 365 许可且可访问 Learning Agent 的用户都可以使用。3. Copilot 入门提示词：入门提示词带着新用户完成一项真实任务，同时教会他们 Copilot 的用法。打开 Learning Agent，选择主页卡片或输入“Start Copilot training”即可开始；用户随后从自己的工作中选一项任务（如起草项目计划），在简短的引导流程中完成。它教授的提示词结构有四个部分：说明目标、提供背景、指明来源、讲清对结果的期望。据支持文档，完整会话还包括 Copilot 功能介绍、结合角色示例的提示词基础、动手练习任务、组织 AI 指引回顾（如有）以及完成前的小测验。4. 提示词辅导：辅导覆盖练习环节。可从技能提升标签页的卡片启动，或请 Learning Agent 帮忙练习提示词。它取用户当前工作的一个场景，帮助界定目标、背景与来源，以及好的结果是什么样子；先从引导式选择开始，再自己写提示词。微软的示例是把会议记录变成团队动态：辅导会问动态面向谁、用哪些记录、输出应是摘要、决策清单还是下一步；用户随后查看模拟的 Copilot 回复、获得反馈并修改提示词；最后可对比最初与最终的提示词，把成品带进 Copilot 使用。微软称，随着用户越来越熟练，指引会逐步减少。

个性化与隐私：管理员应核查的内容。为给出针对每个用户的建议，微软称 Learning Agent 使用 Work IQ 记忆，加上 Teams、聊天、邮件、会议记录以及人员与组织数据中的上下文。例如，花大量时间写周报的人会被建议如何让 Copilot 汇总邮件、聊天与文件，生成带进展与下一步的动态。对应的消息中心公告 MC1556094 给出时间与前提：个性化体验自 2026 年 11 月中旬至 12 月下旬推送，需要特定的管理员与用户设置；用户侧须在 Microsoft Copilot 设置中开启聊天记录与工作洞察开关；合规说明称，该体验使用用户工作活动中的信息，包括 Teams 聊天、邮件与会议记录。旧版文档对数据用途的描述不同：Microsoft Learn 的常见问题称 Learning Agent 使用组织角色与学习偏好，不访问私人文件或 Teams 聊天；这些问答很可能写于新个性化层之前。隐私与合规团队应自行审阅新的数据用途，不要依赖旧版问答措辞；在推送前把问题说清楚，好过事后有人问学习工具怎么知道其会议记录内容。

管理员设置：入职培训、AI 政策与完成情况跟踪。微软还称，管理员可通过 Microsoft 365 管理中心把组织的 AI 使用政策加入培训；目前该选项仅面向 Frontier（微软的早期体验计划）提供。Microsoft Learn 关于推广 Copilot 入职培训的页面列出以下要求：租户须加入 Frontier 并启用 Frontier 功能，教育与政府云租户除外；租户订阅为 Microsoft 365 E3、E5、Business Basic、Business Standard 或 Business Premium；用户许可须通过 Copilot 许可或符合条件的企业/商业订阅获得 Copilot Chat 访问权限；管理员角色为全局管理员或知识管理员（设置与报告）与 AI 管理员（仅设置）；必需开关为按用户启用 Copilot Chat 与 Learning Agent、租户开启 Web 搜索依据；平台为 Windows（Copilot 桌面应用）与网页版，macOS 与移动端不受支持；语言仅英语。设置分四步：在管理中心“Copilot > 设置 > Microsoft Copilot 入职设置”中确认资格；添加 AI 政策链接（可选）；分享体验（复制 Copilot 应用、Copilot 网页版或 Teams 中 Copilot 的链接，或下载并自定义邮件模板；微软估计会话耗时 10 至 15 分钟）；监控完成情况（如启用 Viva Learning，可用其报告查看完成状态）。另有几项限制值得注意：入职培训没有单独许可或额外费用；用户答案不保存，报告仅显示完成状态；Viva Learning 报告不是正式记录，如需可审计的培训记录，仍应使用 HRIS 或 LMS；完成数据可能延迟。微软尚未发布新标签页、播放列表与辅导的完整许可与可用性表，告知员工之前须先核查自己的租户。

原文

Microsoft has given Learning Agent, the learning experience built into Microsoft 365 Copilot, a new job. It used to work mainly as a course catalog. Now it is supposed to coach people while they work. In a Microsoft Copilot Blog post on November 17, 2026, Microsoft announced four additions: a dedicated AI upskilling tab, curated AI Skills Navigator playlists, contextual Copilot starter prompts, and a guided prompt coaching experience. The goal is to move employees from knowing what Copilot and Cowork can do to using them in daily work with some confidence. The announcement comes during Microsoft Ignite week.

Learning Agent itself isn't new. Microsoft describes it as the "enterprise learning front door" it introduced earlier this year. An archived Message Center notice said the Learning Agent in Microsoft 365 Copilot is becoming generally available in June 2026, enhancing AI-driven upskilling with personalized learning plans, skill assessments, and role play scenarios. According to Microsoft, customers have rolled the agent out alongside Copilot, and their feedback kept asking for the same three things: guidance tied to real work, a practical first step, and somewhere to practice. Each of the four new features maps to one of those requests. Microsoft's deployment guidance says in the Microsoft 365 admin center, go to the Agents page, and search for the Learning (Frontier) agent. Users can also find it themselves: from Microsoft Copilot, go to the Agent Store by selecting All agents, then search "Learning." The November update adds features to a service that already exists. If Learning Agent is disabled in your tenant, none of this will reach your users.

The four new experiences. 1. The AI upskilling tab: Microsoft calls the new tab a personalized home for building skills in AI, Microsoft 365 Copilot, Cowork, and Microsoft's first-party agents. It combines practical guidance with learning suggestions so users can see what to try next. Users can ask the agent directly, with prompts such as "How can I use Copilot to create a project plan?" or "What should I learn before trying Copilot Cowork?" 2. AI Skills Navigator playlists: Microsoft added AI Skills Navigator content to Learning Agent earlier this year. The feature lets users build skills through interactive video experiences that combine step-by-step guidance, AI coaching, and hands-on practice. The new step is curated playlists that bundle courses, modules, and videos. Users can pick a playlist from the upskilling tab or ask for one in chat. Microsoft's examples include an "AI at work" playlist that starts with AI basics and moves on to Chat, Cowork, Autopilot, and Code, plus prompts that ask for playlists on sales, marketing campaigns, or faster code reviews. The practical benefit is that modules and videos open next to the Copilot conversation. AI Skills Navigator content is available to Microsoft Copilot users and Copilot Chat users. Anyone with a Microsoft 365 license who has access to Learning Agent can use it. 3. Copilot starter prompts: starter prompts walk new users through a real task while teaching them how Copilot works. To begin, open Learning Agent and either pick a homepage card or type "Start Copilot training". Users then choose a task from their own work, such as drafting a project plan, and complete it in a short guided sequence. The prompt structure it teaches has four parts: state the goal, provide context, identify sources, and spell out what you expect from the response. According to the support documentation, the full session also covers an introduction to what Copilot can do, prompting basics with role-relevant examples, a hands-on task to practice using Copilot, a review of organizational AI guidance, where available, and a short knowledge check before completion. 4. Prompt coaching: the prompt coach covers practice. Start it from a card on the upskilling tab or ask Learning Agent to help you practice prompting. It takes a scenario from your current work and helps you define the goal, the context and sources, and what a good result looks like. You begin with guided choices and then write your own prompt. In Microsoft's example, a user wants to turn meeting notes into a team update. The coach asks who the update is for, which notes to use, and whether the output should be a summary, a list of decisions, or next steps. The user then reviews a simulated Copilot response, gets feedback, and revises the prompt. At the end you can compare your first and final prompts and take the finished one into Copilot. Microsoft says the guidance gradually steps back as you get more confident.

Personalization and privacy: what admins should check. To make recommendations specific to each user, Microsoft says Learning Agent uses Work IQ memory plus context from Teams, chats, emails, meeting transcripts, and people and org data. In Microsoft's example, someone who spends hours on weekly status reports is shown how to have Copilot summarize emails, chats, and files into an update with progress and next steps. The matching Message Center notice, MC1556094, gives timing and prerequisites. It says the personalized experience is rolling out from mid-November to late December 2026 and requires specific admin and user settings. On the user side, an archived copy of the notice says users should ensure the Chat history and Work Insights toggle is enabled in their Microsoft Copilot settings. Its compliance note says the experience uses information from users' work activities, including Teams chats, emails, and meeting transcripts. Older documentation describes the data use differently: Microsoft Learn's FAQ says Learning Agent uses organizational role and learning preferences from Microsoft's learning ecosystem but doesn't access private files or Teams chats. Those FAQs were most likely written before the new personalization layer. Privacy and compliance teams should review the new data use themselves and not rely on the older FAQ wording. It is better to settle the question before rollout than after someone asks how the learning tool knew about their meeting transcript.

Admin setup: onboarding, AI policy, and completion tracking. Microsoft also says admins can add their organization's AI usage policy to the training through the Microsoft 365 admin center. For now that option is available only in Frontier, Microsoft's early-access program. Microsoft Learn's page on rolling out Copilot onboarding lists the requirements: tenant must be enrolled in Frontier with Frontier features enabled; EDU and government cloud tenants excluded; tenant subscription Microsoft 365 E3, E5, Business Basic, Business Standard, or Business Premium; user license Copilot Chat access via a Copilot license or eligible Enterprise/Business subscription; Business Basic, Dynamics, and Teams-only user licenses unsupported; admin roles Global Admin or Knowledge Admin for settings plus reporting, AI Admin for settings only; required toggles Copilot Chat and Learning Agent enabled per user, Web Search Grounding on for the tenant; optional AI policy URL and Viva Learning (needed only for completion tracking); platforms Windows (Copilot desktop app) and web (Edge, Chrome, Firefox, Safari), macOS and mobile not supported; language English only. Setup takes four steps: confirm eligibility under Copilot > Settings > Microsoft Copilot onboarding settings in the Microsoft 365 admin center; add your AI policy link (optional); share the experience by copying a link for the Copilot app, Copilot web, or Copilot in Teams, or download and customize the email template (Microsoft estimates the session takes 10 to 15 minutes); monitor completion, using Viva Learning reporting if enabled. Several limits are worth knowing: the onboarding has no separate license or added cost; users' answers are not saved, and reporting shows completion status only; Viva Learning reporting is not a formal record, so if you need auditable training records, keep using your HRIS or LMS; completion data can be delayed. Microsoft has not published a full licensing or availability table for the new tab, playlists, and coach, so check your own tenant before telling staff they have everything.
