微软发布了 Windows 11 2026 年 10 月补丁日更新，共修复 1413 个漏洞。10 月 13 日的版本同时是 Windows 11 24H2 家庭版和专业版的最后一次月度安全更新，这些用户必须升级到受支持版本才能继续获得安全修复。

最紧急的修复是 CVE-2026-96951，一个已被攻击者利用的 Windows Shell 命令注入漏洞，可绕过 Mark of the Web（MOTW）防护。MOTW 标记来自互联网的文件，让 Windows 和应用程序施加额外安全检查；绕过它会让用户打开恶意文件时更加危险。利用需要用户交互，例如打开特制附件或点击经邮件/即时消息发送的攻击者链接。公告致谢了 Fujitsu 研究员 Riku Bamba 和 Yuya Chudo、使用 Claude 的 Anthropic 研究员 Benoit Sevens，以及署名 yhw 的研究员。

10 月安全版本还修复了 CVE-2026-108398，一个由 Google Project Zero 的 James Forshaw 报告的公开 .NET Framework 漏洞。经认证的本地攻击者可用特制 .NET 程序集绕过 Windows Defender 应用程序控制，在受保护进程中执行未授权代码；微软表示该漏洞暂未被利用。

KB5127648 覆盖 24H2、25H2 和 26H2，KB5127646 更新 26H1。两个更新包都修复了 Explorer.exe 启动失败和多用户环境（含 Azure Virtual Desktop 和 FSLogix）下的反复崩溃——此前用户登录后可能面对黑屏；还修复了 Always On VPN 在自动协议选择或回退时的连接失败——受影响连接可能卡在「正在连接」或失败后报错端口已被占用。其他修复包括恢复无法上线的分层 Storage Spaces Direct 虚拟磁盘、解决部分游戏中的鼠标输入卡顿。

原文

Microsoft released its October 2026 Patch Tuesday updates for Windows 11, addressing 1,413 vulnerabilities. The October 13 release also delivers the final monthly security update for Windows 11 24H2 Home and Pro, whose users must upgrade to a supported version to continue receiving security fixes.

The most urgent fix addresses CVE-2026-96951, a Windows Shell command-injection vulnerability that attackers have already exploited to bypass Mark of the Web (MOTW) defenses. MOTW identifies files originating from the internet so Windows and applications can apply additional security checks; evading those protections makes malicious files more dangerous when users open them. Exploitation requires user interaction, such as opening a specially crafted attachment or following an attacker-controlled link delivered through email or instant messaging. The advisory credits Fujitsu researchers Riku Bamba and Yuya Chudo, Anthropic's Benoit Sevens using Claude, and a researcher identified as yhw.

The broader October security release also fixes CVE-2026-108398, a publicly disclosed .NET Framework vulnerability credited to Google Project Zero's James Forshaw. An authenticated local attacker could use a crafted .NET assembly to bypass Windows Defender Application Control and execute unauthorized code within a protected process; Microsoft reports no exploitation of this flaw.

KB5127648 covers versions 24H2, 25H2 and 26H2, while KB5127646 updates version 26H1. Both packages repair Explorer.exe startup failures and repeated crashes in multi-user environments, including Azure Virtual Desktop and FSLogix, which could leave users facing a black screen after signing in. They also address Always On VPN failures involving automatic protocol selection or fallback — affected connections could remain stuck while connecting or fail after an unsuccessful attempt. Other fixes restore tiered Storage Spaces Direct virtual disks that failed to come online and resolve mouse-input stutter in some games.
