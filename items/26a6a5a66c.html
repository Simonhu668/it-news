2026 年 10 月 19 日，微软 365、Copilot 与 SharePoint 咨询公司 eSoftware Associates（ESW）发布了一份 Copilot 智能体定价与治理指南，聚焦 Copilot Studio 自主智能体。背景是微软在 10 月 15 日预览了智能体账户、共享内存与新触发器，让 Copilot Studio 智能体无需用户提示就能承担更多工作；这些功能通过微软 Frontier 计划预览。智能体运行按 Copilot Credits 计费——即使组织已经买了 Microsoft 365 Copilot 许可证也要另付费，所以定价必须在搭建智能体之前规划好。按微软 2026 年 10 月公开价目（可能调整，ESW 转述）：每次触发计为一次可计费的智能体动作，生成式回答用 2 个 credits，智能体动作用 5 个，推理模型额外加收。Credit 包售价 25,000 credits/200 美元/月，未用完不结转。指南中的测算示例：一个每 10 分钟跑一次、每次 1 次触发加 2 次工具调用加 1 次回答的智能体，一月约用 73,000 credits，接近 3 个包；同样配置每天跑一次则约 510。ESW 首席执行官 Russell Kommer 说：'排程往往是最大的成本决定因素，而人们五秒钟就定下来了。我担心的是智能体一旦有了邮箱，人们会把没人评估过的工作都丢给它。'指南建议第一个 Copilot 智能体上线前先落实治理：每个智能体设带硬停止的 credit 上限；智能体运行环境设容量上限；排程按工作实际需要的频率定；每个智能体指定负责人；打开 Microsoft Purview 审计；任何按排程运行、发邮件或写系统记录的智能体，发布前先评审。ESW 建议从一个流程开始：'一个有明确负责人和签核人的重复性流程。不是五个智能体，就一个。'

原文

New York, NY, Oct. 19, 2026 (GLOBE NEWSWIRE) -- eSoftware Associates Inc. (ESW), a Microsoft 365, Copilot and SharePoint consultancy, has published a guide to Copilot agent pricing and governance, with a focus on autonomous agents in Copilot Studio. The guide follows Microsoft's October 15, 2026 preview of agent accounts, shared memory and new triggers that let Copilot Studio agents take on more work without a user prompt. The features are in preview through Microsoft's Frontier program. Agent runs are billed in Copilot Credits, even for organizations that already pay for Microsoft 365 Copilot licenses, so pricing has to be planned before the agent is built. What an autonomous Copilot agent costs depends mostly on how often it runs and what it does each time. Under Microsoft's published list rates as of October 2026, which may change, every trigger counts as a billable agent action, a generative answer uses 2 credits, an agent action uses 5, and reasoning models add premium charges on top. Credit packs are sold at 25,000 credits for $200 a month, and unused credits do not roll over. In an illustrative example in ESW's guide, an agent scheduled to run every 10 minutes, with one trigger, two tool calls and one answer per run, would use about 73,000 credits a month, close to three packs. The same agent running once a day would use about 510. "The schedule tends to be the biggest cost decision, and someone makes it in five seconds," said Russell Kommer, CEO of ESW. "My concern is what happens once an agent has a mailbox. People will start handing it work nobody scoped." The guide recommends that organizations put AI agent governance in place before the first Copilot agent goes live: a credit cap with a hard stop on each agent; a capacity cap on the environment the agent runs in; a schedule that matches how often the work actually needs to happen; a named owner for every agent; Microsoft Purview auditing turned on; a review before publishing any agent that runs on a schedule, sends email or writes to a system of record. ESW recommends starting with one process: "One recurring process with a clear owner and a person who signs off. Not five agents. One."
