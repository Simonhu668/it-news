正文 · AI 翻译

Microsoft 正重新定义 Microsoft Copilot，以配合工作模式持续演进，协助每位用户与每个组织在实现目标的过程中拓展更多可能。今天，Microsoft 正式推出全新 Copilot，串联人们日常依赖的工具与新一代 AI 能力，协助企业更轻松地建立、自订并扩展 AI 应用。

Copilot 应用程序新增三项全新功能：Home 整合 Chat 与 Cowork，成为全新的工作起点，透过 Office in Copilot 更将 Word、Excel 与 PowerPoint 的功能完整整合至体验中；Code 采用与 GitHub Copilot 相同的底层技术，提供可安全执行的工具，协助每位用户打造专属的解决方案；Autopilot 则是持续运作、主动执行任务的个人化 agent，即便在使用者离线时也能推进任务。其中，Home 与 Code 功能将于未来几周透过 Frontier 计划推出；而 Autopilot 则将于本月底扩展至开放私人预览。

为不同工作模式而设的全新体验

Home 整合 Chat 与 Cowork，为用户提供统一的工作体验。随着工作持续在会议、即时讯息、文件、电邮、应用程序及 agents 之间切换，Home 协助用户随时掌握进度，让工作更有条理并持续推进。用户可透过 Home 检视近期活动、取得 Copilot 能协助处理的工作建议，并从上次中断的位置接手执行工作。Chat 提供即时且自然的对话体验，协助快速回复、查询信息、草稿撰写，以及即时了解最新进展。Cowork 则适用于委派任务，使用者只需定义任务内容，即可交由 Cowork 由头到尾自主执行整个流程，并交付成果。未来，用户将无需手动选择模式，只需描述希望完成的事情，Copilot 便能自动判断并将工作分派至 Chat、Cowork 或 Code，以最适合的功能完成任务。

Code 让建立解决方案不再只局限于开发人员。用户只要透过自然语言描述所需的应用程式、追踪工具、仪表板、自动化流程或业务工作流程，Copilot 就能自行选择最合适的方案并完成建置，无论是方便快速查阅的长驻桌面小工具、用于探索数据与测试结果的互动式仪表板，或是可与团队共享的云端托管内部应用程序皆可自动完成。

Code 采用与 GitHub Copilot 相同的底层技术，并在沙盒环境中执行，可以安全地部署于企业租户内部。透过 Microsoft IQ，用户所建立的一切将以其工作情境为基础，并可自动与各类外挂程式同步。软体开发人员可持续使用 GitHub Copilot 处理日常工作，同时与 Copilot 平台创造更深层的整合能力。Code 将于本月底透过 Frontier 计划推出，并于未来几周扩大开放；今年稍后亦将以预览形式提供给 Microsoft 365 Premium 与 Microsoft 365 Pro 订阅用户。

随着 Copilot 让建立解决方案变得更简单快捷，Microsoft 同时推出 Microsoft Copilot Managed Runtime，这是一套可直接在 Microsoft 365 企业环境中安全执行程式码的托管基础架构。此平台由 IT 团队负责管理，用户可轻松与团队成员分享应用程序、连接即时资料，并随时随地存取。相同的架构也支援在 Cowork、Code 和 Copilot Studio 中建立的应用程序，并开放第三方开发人员及专业程式开发人员使用。Copilot Managed Runtime 目前已进入预览阶段，未来将可于 Code 中直接使用。

Autopilot 是用户的数码工作伙伴，只需设定名称、角色与工作目标，Autopilot 便可开始执行任务，包括监测频道、追踪进度、执行例行性工作，以及在数天后重新接手先前未完成的工作，整个过程无需等待用户发出指令。例如，Autopilot 可建立并管理完整的供应商审查流程，从制定时间表与工作计划，到自行处理前置作业、会议安排与后续追踪，甚至主动联系相关持份者掌握最新进度。此外，Autopilot 采用云端托管架构，即使用户正在休息或忙于其他工作时仍能持续运作，无须即时监控。

Autopilot 具备专属身分、记忆、运算环境与工作空间，并建基于 Microsoft IQ，因此可理解企业的实际运作方式。Autopilot 运行于用户日常的工作环境中，包括 Teams、Outlook、聊天对话、频道与文件，如同与同事互动一般，用户可透过 @ 标注 Autopilot。同时，Autopilot 也具备完善的权限管理、审核与治理机制，用户只需设定目标与执行界限，Autopilot 便会负责后续工作，并持续回报进度、让决策权始终掌握在用户手中。

拓展企业工作情境

Copilot 以 Microsoft IQ 为核心基础。Microsoft IQ 是 Microsoft 企业 AI 的统一整合智能平台，串联 Microsoft 技术环境中的各项服务，整合企业营运所掌握的知识，协助 Copilot 与各类 agents 即时掌握完整信息，并在安全且受治理的环境执行任务。

管理 AI 成本

针对快速问答、初稿撰写、内容摘要与分析等日常 AI 应用，企业通常期望在固定成本下获得最佳品质。Microsoft 透过用户订阅授权（User Subscription License，USL）提供这种模式，涵盖 Copilot Chat，以及在 Word、Excel、PowerPoint、Outlook 及 Teams 中使用，并提供新功能与新模型。Auto 是用户订阅授权的核心机制，可根据每次任务所需的准确性、速度与成本，选择最适合的模型执行任务。代理式（Agentic）工作则需不同的成本模式，以便用户运用最先进的模型获得最佳品质。用量计费（Usage-Based Billing，UBB）机制提供完整的控制能力，企业可自行选择模型，依据实际价值弹性调整支出。Cowork、Code、Autopilot、全新可长时间运行的代理能力，以及 Astra、Fable 等前瞻模型均采用用量计费模式。

FinOps for AI 是管理 AI 支出并提升其商业价值的专业领域。Microsoft 致力协助企业充分发挥 AI 成本效益，并于今天宣布于 Agent 365、Insights 与 Microsoft Copilot 推出多项新功能，协助企业管理 AI 成本。Agent 365 的成本管理功能正从过去支援 Cowork 与 Work IQ APIs，进一步扩展至 Code 及 Copilot Managed Runtime，并预计将于 10 月进一步支援透过 Microsoft Copilot Studio 建立的 agents。管理员将可以透过 API 大规模管理支出政策，将终端用户的额度申请需求串联至现有的核准与自动化工作流程，并为不同用户群组设定可使用的模型系列，而这些设定也将影响 Auto 可自动选择的模型范围。
