微软于周二发布了有史以来最大的一批安全修复。2026 年 10 月的“补丁星期二”共修复 1,413 个漏洞，其中一个已在野外被实际利用。

这一数字打破了此前的所有纪录，超过了微软在 2025 年全年修复的漏洞总数，而且距离上月创下新高仅过去一个月。漏洞激增反映了 Windows、Office 和云服务代码的复杂性加深，也表明人工智能如今比人类更快地发现漏洞。

微软官方安全更新指南给出了分类数据：Windows 占 1,102 个，Office 134 个，SharePoint Server 36 个，开发工具 61 个，还涉及 SQL Server、Exchange、Azure、Defender 等。管理员总共需要安装 176 个独立更新。

这 1,413 个问题中，78 个为严重级别，多为远程代码执行；另有 677 个为权限提升漏洞。

最需要立即关注的是 CVE-2026-96951：该漏洞影响 Windows Shell，允许未认证攻击者绕过 Mark of the Web 保护（该机制会警告用户文件来自互联网下载）。微软确认该漏洞已在野外被利用，CISA 已将其加入已知被利用漏洞目录，并要求联邦机构在 10 月 16 日前修复。

Tenable 高级研究工程师 Satnam Narang 指出，这是今年第三个在野外被利用的 Windows Shell 漏洞，此前两个与 APT28（Fancy Bear）有关。2026 年 1 月至 10 月已修复 26 个 Windows Shell 漏洞，而 2025 年全年只有 3 个。

另外两个零日漏洞也得到修复，目前未见实际利用：CVE-2026-108398 影响 .NET Framework，允许已认证攻击者绕过 Windows Defender 应用控制；另一个与 MessagePack 处理相关，可能导致拒绝服务。

Office 方面受创严重：Excel 单独收到 69 个补丁，其中 11 个是严重级远程代码执行；Outlook 有 5 个严重漏洞，Word 有 2 个。这是 Office 2021 与 LTSC 2021 的最后一次安全更新，支持已于 10 月 13 日结束，仍在使用这些版本的组织必须迁移。

规模之大迫使微软改变数据呈现方式：首次将漏洞分组为“风险分组”（risk cohorts），以帮助防御者更快确定优先级。

生命周期到期也加剧压力：Windows 11 24H2 家庭版和专业版收到最后一个累积更新；Windows 10 企业版 LTSB 2016 迎来最终补丁；Windows Server 2012/2012 R2 的扩展安全更新结束；Exchange Server 2016 和 2019 也到期。微软警告客户升级，否则系统将失去保护。

一年前的 10 月补丁日仅约 180 个修复，2026 年累计补丁已超过 4,000 个。每月测试数千个补丁让即使资源充足的 IT 团队也吃力。部署窗口缩短，一些管理员习惯推迟一周打补丁以观望问题。随着纪录逐月被打破，这种谨慎策略可能已不够用。

目前建议仍然简单：更新 Windows、更新 Office、检查所有受支持产品，并为未来更大的补丁做好准备。

原文

Microsoft on Tuesday released its largest-ever batch of security fixes. The October 2026 Patch Tuesday addresses 1,413 vulnerabilities. One of them is already being attacked in the wild.

That total shatters previous records. It exceeds the entire vulnerability count Microsoft fixed in 2025, and it comes just one month after the company set a new high in September. The surge reflects deeper code complexity across Windows, Office and cloud services. It also shows how artificial intelligence now helps surface bugs faster than humans alone ever could.

Microsoft's official security update guide breaks down the numbers. Windows accounts for 1,102 of the flaws. Office follows with 134. SharePoint Server has 36. Developer tools add 61 more. The list stretches across SQL Server, Exchange, Azure, Defender and beyond. In all, administrators face 176 distinct updates.

Of those 1,413 issues, 78 rank as critical. Most allow remote code execution. Another 677 enable privilege escalation.

Yet one flaw demands immediate attention. CVE-2026-96951 affects Windows Shell. It lets unauthenticated attackers bypass the Mark of the Web protection that warns users about files downloaded from the internet. Microsoft confirms exploitation in the wild. CISA added the bug to its Known Exploited Vulnerabilities catalog and ordered federal agencies to patch by October 16.

Satnam Narang, senior staff research engineer at Tenable, noted this marks the third Windows Shell vulnerability exploited in the wild this year. Previous ones tied back to APT28, also known as Fancy Bear. There have been 26 Windows Shell vulnerabilities patched in 2026 through October, compared to just three in all of 2025.

Two other zero-days also received fixes. Neither shows active exploitation yet. CVE-2026-108398 hits the .NET Framework, allowing an authenticated attacker to bypass Windows Defender Application Control. The second, tied to MessagePack processing, could lead to denial of service.

Office took heavy hits too. Excel alone received 69 patches, including 11 critical remote code execution bugs. Outlook saw five critical issues. Word added two more. And this marks the final security update for Office 2021 and LTSC 2021. Support ended October 13. Organizations still running those versions must migrate now.

The sheer scale forced changes in how Microsoft presents the data. For the first time the company grouped vulnerabilities into risk cohorts. The goal is to help defenders prioritize faster.

End-of-support deadlines added pressure. Windows 11 version 24H2 Home and Pro editions received their last cumulative update. Windows 10 Enterprise LTSB 2016 also reached its final patch. Windows Server 2012 and 2012 R2 finished their extended security updates. Exchange Server 2016 and 2019 followed suit. Microsoft warned customers to upgrade or face unprotected systems.
