Veeam 2026 年 10 月 27 日发布安全公告 KB4957，Veeam Backup for Microsoft 365 8.6 修复四处缺陷，全部经 HackerOne 报告。第一处 CVE-2026-106076，严重程度为 Critical，CVSS v4.0 评分 9.0：经认证的组织迁移对端可向源端 Veeam Backup for Microsoft 365 服务器的配置数据库注入 SQL，导致跨租户读写配置数据，并以 PostgreSQL 服务账户执行远程代码。受影响产品为 Veeam Backup for Microsoft 365 8.5.0.1014 及全部更早版本 8 构建；未受支持的产品版本未经测试，但可能受影响，应视为存在缺陷。修复自 8.6（构建号 8.6.0.1102）起提供。第二处 CVE-2026-106077，严重程度为 High，CVSS v4.0 评分 8.3：持有 Veeam Backup for Microsoft 365 管理员角色的用户可以 LocalSystem 权限读取备份服务器上的任意文件。受影响产品与第一处相同，修复同样自 8.6（8.6.0.1102）起提供。第三处 CVE-2026-106078，严重程度为 Medium，CVSS v4.0 评分 6.9：未认证攻击者可使用伪造的联合令牌绕过 REST API 认证，并收到不调用备份服务的 REST API 端点的响应。受影响产品为 8.6.0.1102 及全部更早版本 8 构建，修复自 8.6 Patch 1（构建号 8.6.0.5011）起提供。第四处 CVE-2025-64394，严重程度为 Medium，CVSS v4.0 评分 4.3：低权限本地用户可在安装 Veeam Backup for Microsoft 365 期间以 SYSTEM 权限写入任意文件，可能导致权限提升或拒绝服务。受影响产品与第三处相同，修复同样自 8.6 Patch 1（8.6.0.5011）起提供。Veeam 在公告中提醒：缺陷与补丁一旦公开，攻击者可能尝试对补丁做逆向工程以利用未打补丁的部署，因此须及时安装最新版本与全部更新。公告未说明在野利用情况。

原文

Veeam published security advisory KB4957 on October 27, 2026: Veeam Backup for Microsoft 365 8.6 resolves four vulnerabilities, all reported through HackerOne. CVE-2026-106076, Severity: Critical, CVSS v4.0 Score: 9.0. A vulnerability allowing an authenticated organization-transfer peer to inject SQL into the configuration database of the source Veeam Backup for Microsoft 365 server, leading to cross-tenant read and write of configuration data and remote code execution as the PostgreSQL service account. Affected product: Veeam Backup for Microsoft 365 8.5.0.1014 and all earlier version 8 builds. Note: Unsupported product versions were not tested, but are likely affected and should be considered vulnerable. Solution: fixed starting in Veeam Backup for Microsoft 365 8.6 (build 8.6.0.1102). CVE-2026-106077, Severity: High, CVSS v4.0 Score: 8.3. A vulnerability allowing a user with the Veeam Backup for Microsoft 365 Administrator role to read arbitrary files on the backup server with LocalSystem privileges. Affected product: 8.5.0.1014 and all earlier version 8 builds. Solution: fixed starting in 8.6 (build 8.6.0.1102). CVE-2026-106078, Severity: Medium, CVSS v4.0 Score: 6.9. A vulnerability allowing an unauthenticated attacker to bypass REST API authentication with a forged federation token and receive responses from REST API endpoints that do not call the Veeam Backup for Microsoft 365 backup service. Affected product: 8.6.0.1102 and all earlier version 8 builds. Solution: fixed starting in 8.6 Patch 1 (build 8.6.0.5011). CVE-2025-64394, Severity: Medium, CVSS v4.0 Score: 4.3. A vulnerability allowing a low-privileged local user to write arbitrary files with SYSTEM privileges during the installation of Veeam Backup for Microsoft 365, which can lead to privilege escalation or denial of service. Affected product: 8.6.0.1102 and all earlier version 8 builds. Solution: fixed starting in 8.6 Patch 1 (build 8.6.0.5011). Veeam notes in the advisory that once a vulnerability and its associated patch are disclosed, attackers will likely attempt to reverse-engineer the patch to exploit unpatched deployments, underscoring the importance of installing the latest versions and updates without delay. The advisory does not state that exploitation has occurred in the wild.
