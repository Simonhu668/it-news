正文 · AI 翻译

Microsoft 365 Targeted Release（目标发布）即将退役，由围绕三种发布偏好构建的新体系取代：Frontier、Standard 和 Deferred。根据 Microsoft 365 消息中心 MC1490899，从 2026 年 11 月开始影响各组织，2027 年 1 月 Targeted Release 正式关闭。

2026 年 11 月起，组织将无法再为新用户注册 Targeted Release。2027 年 1 月起，微软将停止通过 Targeted Release 向现有注册用户推送更新，完成该通道的退役。

Frontier 让用户在新功能正式发布前提前预览；Standard 在微软正式发布后推送新功能；Deferred 则在 Standard 收到功能后再延迟 30 天，让 IT 团队有时间在广泛部署前评估新功能、发现潜在问题。

微软建议管理员在旧通道消失前，将现有的 Targeted Release 用户迁移到 Frontier、Standard 或 Deferred；若放任不管，2027 年初通道停止推送后，用户预期的功能推出节奏可能发生变化。

目前管理员可在 Microsoft 365 管理中心「设置 > 组织设置 > 组织配置文件 > 发布偏好」中管理注册，但微软计划在 2026 年 11 月统一体系推出时停用该界面，后续会公布管理体验的变更细节。

原文

Microsoft 365 Targeted Release is heading for retirement, to be replaced by a new system built around three release preferences: Frontier, Standard and Deferred. The change will begin affecting organizations in November 2026 before Targeted Release shuts down in January 2027, according to message MC1490899 in the Microsoft 365 Message Center.

Starting in November 2026, organizations will no longer be able to enroll new users in Targeted Release. Microsoft will then stop delivering updates through Targeted Release to existing enrolled users in January 2027, completing the retirement of the channel.

Frontier gives users early preview access to upcoming Microsoft 365 features before they reach general availability, while Standard delivers new features once Microsoft makes them generally available. Deferred holds those features back for 30 days after Standard receives them, giving IT teams time to evaluate new features and identify potential problems before broader deployment.

Microsoft recommends administrators move existing Targeted Release users to Frontier, Standard or Deferred before the old channel disappears; organizations that leave users on Targeted Release could see changes to their expected feature rollout schedules once the channel stops delivering updates in early 2027.

Administrators can currently manage enrollment in the Microsoft 365 admin center under Settings > Org settings > Organization profile > Release preferences, but Microsoft plans to retire that experience when the unified system starts rolling out in November 2026, with more information about changes to the admin experience promised later.
