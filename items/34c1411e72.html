尚未观察到在野利用。Sansec 表示尚未在真实网店中发现 BlockStrap 攻击，但他们在 24 小时内复现了四条不同的攻击路径，预计威胁行动者也能做到。BlockStrap 是六周内 Magento 邮件模板引擎的第二次严重崩塌：与 StyleSmuggler 同为 CVSS 10.0，影响相同——未授权攻击者可在网店服务器上执行任意 PHP 代码。Adobe 补丁：CVE-2026-103849。Adobe 于 10 月 13 日发布 APSB26-153 公告，其中最严重的就是 BlockStrap（模板引擎注入，CVSS 10.0，由研究员 vozec 发现）。受影响产品：Adobe Commerce ≤ 2.4.9；Adobe Commerce B2B ≤ 1.5.3；Magento Open Source ≤ 2.4.9。注意两点：纯 Composer 安装的仍是带漏洞的基础版本，需应用 2026-oct 发行版或 Adobe 的独立补丁；BlockStrap 与 StyleSmuggler 是两个独立的修复，两者都要打，9 月的 VULN-39341 热修复须保留。根因：BlockStrap 与 StyleSmuggler 同属“二次解析指令注入”。9 月的热修复给可信指令加数字签名，但攻击者控制的子模板数据仍可能被签名，并在根层级被重新扫描——此时被走私的 {{block}} 指令会在 Magento 渲染流程中执行。Adobe 的 10 月补丁用“注册占位符”替换了这种通用重扫机制。24 小时复现四条代码执行路径：攻击链虽复杂，但任何人都可以用 AI 智能体在较短时间内把补丁反向工程成可用的攻击脚本——这正是 Sansec 质疑 Adobe 给出“优先级 2（30 天内修复）”评级的原因：StyleSmuggler 从优先级 1 热修复到大规模利用只用了三天，BlockStrap 复杂度相当。商户该怎么做：把团队从休假中叫回来，今天就开始打补丁；若几小时内打不上，Sansec Shield 已在 HTTP 层拦截 BlockStrap（所有 Shield 店铺规则已生效）；运行 eComscan 检查缺失的补丁并排查后门。常见问题：Magento Open Source 2.4.6 有 BlockStrap 补丁吗？没有。Adobe 公开的 10 月补丁只覆盖 2.4.7-p10、2.4.8-p5 和 2.4.9；2.4.4-p18、2.4.5-p17、2.4.6-p15 的补丁需要 Adobe Commerce 许可证，因此 2.4.6 及更早的开源版本店铺须升级到 2.4.7-p10 或更高。Mage-OS 受影响吗？受影响，上至 3.5.0；10 月 14 日发布的 Mage-OS 3.6.0 已包含 Adobe 的修复。9 月的 StyleSmuggler 热修复还用打吗？用。10 月补丁不包含 VULN-39341，且 Adobe 的补丁注册表未将其列为前置条件，因此要单独安装，先于 10 月补丁。如何确认 BlockStrap 补丁已生效？在 Magento 根目录执行 grep -c resolveDeferredDirectives vendor/magento/framework/Filter/Template.php——10 月补丁新增了该函数，返回 0 即表示缺失；即使部署日志无报错也要查代码，Composer 补丁插件可能静默跳过某个 hunk。时间线：2026-09-07 Adobe 发布 StyleSmuggler 热修复（CVE-2026-75650，VULN-39341）；2026-10-13 Adobe 发布 APSB26-153 修复 BlockStrap（CVE-2026-103849），CVSS 10.0，优先级 2；2026-10-14 Sansec 复现四条代码执行路径并部署 Shield 防护；2026-10-15 Sansec 发布本分析，真实店铺中暂未观察到利用。（来源：Sansec 研究分析，安全研究公司口径。）

原文

No exploitation observed yet. Sansec has not seen BlockStrap attacks on live stores. But we managed to reproduce four different attack routes within 24 hours, and expect threat actors to do the same. BlockStrap is the second critical break in Magento's email template engine in six weeks. It has the same CVSS 10.0 score as StyleSmuggler and the same impact: an unauthenticated attacker runs arbitrary PHP on the store server. Adobe patch: CVE-2026-103849. Adobe published APSB26-153 on October 13. The most critical issue is BlockStrap, a template engine injection at CVSS 10.0, found by vozec. Affected products: Adobe Commerce <= 2.4.9; Adobe Commerce B2B <= 1.5.3; Magento Open Source <= 2.4.9. Beware though! A plain Composer install still has the vulnerable base version, so apply the 2026-oct release or Adobe's isolated patch. BlockStrap and StyleSmuggler are separate fixes. You need both, so keep the September VULN-39341 hotfix in place as well. Builds upon StyleSmuggler: BlockStrap is a second-pass directive injection, like StyleSmuggler. The September VULN-39341 hotfix signs trusted directives, but attacker-controlled data in a child template can still be signed and rescanned at the root level, where a smuggled {{block}} directive runs inside Magento's rendering. Adobe's October patch replaces that generic rescan with registered placeholders. Four routes to code execution in 24 hours: The attack path is complex, but anyone with an AI agent can reverse-engineer the patch into working exploits in a relatively short time. That is why we question Adobe's priority 2 rating (patch within 30 days). StyleSmuggler went from a priority 1 hotfix to mass exploitation in three days, and BlockStrap is of similar complexity. What merchants should do: Recall your team from vacation and start patching today. If you cannot patch within hours, Sansec Shield blocks BlockStrap at the HTTP layer, with rules live for all Shield stores. Run eComscan to flag the missing patch and check for backdoors. FAQ: Is there a BlockStrap patch for Magento Open Source 2.4.6? No. Adobe's public October patches cover Magento Open Source 2.4.7-p10, 2.4.8-p5 and 2.4.9. The patches for 2.4.4-p18, 2.4.5-p17 and 2.4.6-p15 need an Adobe Commerce license, so Open Source stores on 2.4.6 or older have to upgrade to 2.4.7-p10 or later. Is Mage-OS affected by BlockStrap? Yes, up to Mage-OS 3.5.0. Mage-OS 3.6.0, released on October 14, contains Adobe's fix. Do I still need the September StyleSmuggler hotfix? Yes. The October patch does not include the StyleSmuggler hotfix VULN-39341, and Adobe's patch registry does not list the hotfix as a prerequisite, so install it separately, before the October patch. How do I check that the BlockStrap patch is applied? Run grep -c resolveDeferredDirectives vendor/magento/framework/Filter/Template.php in the Magento root. The October patch adds this function, so 0 means the BlockStrap fix is missing. Check the code even when your deploy reported no errors. Composer patch plugins can skip a hunk without failing the build. Timeline: 2026-09-07 Adobe ships the StyleSmuggler hotfix (CVE-2026-75650, VULN-39341); 2026-10-13 Adobe publishes APSB26-153 fixing BlockStrap (CVE-2026-103849), CVSS 10.0, priority 2; 2026-10-14 Sansec reproduces four code-execution routes and deploys Shield protection; 2026-10-15 Sansec publishes this analysis; no exploitation observed on live stores yet.
