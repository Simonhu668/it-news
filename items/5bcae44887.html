美国网络安全与基础设施安全局（CISA）已将 Apache Axis、Vanderbilt REDCap、BerriAI LiteLLM 与 Synology DSM 的缺陷列入已知被利用漏洞（KEV）目录。本次列入的缺陷如下：

- CVE-2024-10441（CVSS 9.8 分）：Synology DiskStation Manager（DSM）输出编码或转义不当缺陷 - CVE-2026-40217（CVSS 8.8 分）：BerriAI LiteLLM 未受保护的备用通道缺陷 - CVE-2026-90436（CVSS 9.8 分）：Apache Axis 不安全反射缺陷 - CVE-2026-90817（CVSS 9.8 分）：Vanderbilt 大学研究电子数据采集（REDCap）代码注入缺陷

第一项缺陷 CVE-2024-10441（CVSS 9.8 分）影响 Synology DiskStation Manager（DSM），由输出编码或转义不当造成。Synology 已确认攻击者正在利用该缺陷对网络附加存储（NAS）设备发起勒索攻击，入侵已导致部署 C3RB3R 勒索软件，使易受攻击设备上的数据面临风险。

第二项缺陷 CVE-2026-40217（CVSS 8.8 分）影响 BerriAI LiteLLM，属于未受保护的备用通道缺陷。Google 威胁情报组报告称，攻击者已利用它把受限的推理密钥提升为完整管理员凭据，随后建立持久立足点开展 LLM 劫持攻击，滥用被攻陷的 AI 基础设施访问大语言模型。攻击活动针对北美、南美与亚太地区的金融服务、零售、交通与技术行业组织。

第三项缺陷 CVE-2026-90436（CVSS 9.8 分）影响 Apache Axis 1.x，涉及不安全反射。启用远程 API 功能时，该缺陷可在 Atlassian Confluence Data Center 中导致远程代码执行。Rapid7 于 2026 年 11 月 13 日在客户环境中发现攻击者正在利用它。攻击者执行了 Shell 命令，并通过临时的 Pinggy 与 Cloudflare Tunnel 域名下载脚本，随后在被攻陷系统上搜索敏感信息，包括凭据、令牌、VPN 配置与私钥；攻击者还查询内部服务并试图获取更多凭据，部分尝试失败，但最终拿到一个服务账号凭据并访问了一个生产云数据仓库，随后用该账号登录了 Microsoft 365。Apache Axis 1.x 已终止支持，该分支没有官方修复，组织应迁移到其他 SOAP 框架或应用可用的社区补丁。

第四项缺陷 CVE-2026-90817（CVSS 9.8 分）影响 Vanderbilt 大学的研究电子数据采集（REDCap）平台，属于代码注入缺陷。攻击者可通过特制 HTTP 请求触及非预期的控制器路由，在数据导入操作期间操纵文件路径或流，从而加以利用；利用须知道有效的公开调查问卷哈希值。Safe Security 观察到一名未知攻击者利用该缺陷部署临时 Web Shell，随后通过内存加载器取回 XMRig 加密货币挖矿程序；攻击者把挖矿程序伪装成图片文件与合法的 syslog-ng 进程，并通过计划任务与新增 SSH 密钥建立持久化。

CISA 已为联邦机构设定修复期限，要求在 2026 年 11 月 21 日或 12 月 2 日前处理 Synology、LiteLLM、Apache Axis 与 REDCap 缺陷（按缺陷区分）。在野利用报告再次说明，组织须识别暴露的系统、应用可用修复或缓解措施，并排查可能的入侵迹象。

原文

The U.S. Cybersecurity and Infrastructure Security Agency (CISA) added Apache Axis, Vanderbilt REDCap, BerriAI LiteLLM, and Synology DSM flaws to its Known Exploited Vulnerabilities (KEV) catalog. Below are the flaws added to the catalog:

- CVE-2024-10441 (CVSS score of 9.8) Synology DiskStation Manager (DSM) Improper Encoding or Escaping of Output Vulnerability - CVE-2026-40217 (CVSS score of 8.8) BerriAI LiteLLM Unprotected Alternate Channel Vulnerability - CVE-2026-90436 (CVSS score of 9.8) Apache Axis Unsafe Reflection Vulnerability - CVE-2026-90817 (CVSS score of 9.8) Vanderbilt University Research Electronic Data Capture (REDCap) Code Injection Vulnerability

The first vulnerability, CVE-2024-10441 (CVSS score 9.8), affects Synology DiskStation Manager (DSM) and is caused by improper encoding or escaping of output. Synology has confirmed that attackers are exploiting the flaw in ransomware attacks targeting network-attached storage (NAS) devices. The intrusions have resulted in the deployment of C3RB3R ransomware, putting data stored on vulnerable devices at risk.

The second flaw, CVE-2026-40217 (CVSS score 8.8), affects BerriAI LiteLLM and is classified as an unprotected alternate channel vulnerability. Google Threat Intelligence Group reported that attackers have exploited it to escalate limited-access inference keys into full administrative credentials. They then established persistence to conduct LLMjacking attacks, abusing compromised AI infrastructure to access large language models. The campaigns targeted organizations in the financial services, retail, transportation and technology sectors across North America, South America and the Asia-Pacific region.

The third vulnerability, CVE-2026-90436 (CVSS score 9.8), affects Apache Axis 1.x and involves unsafe reflection. The flaw can allow remote code execution in Atlassian Confluence Data Center when the Remote API feature is enabled. Rapid7 detected attackers exploiting it in a customer environment on November 13, 2026. The threat actors executed shell commands and downloaded scripts through temporary Pinggy and Cloudflare Tunnel domains. They then searched the compromised systems for sensitive information, including credentials, tokens, VPN configurations and private keys. The attackers also queried internal services and attempted to obtain additional credentials. Although some of these attempts failed, they managed to acquire a service account credential and access a production cloud data warehouse. They later used the account to sign in to Microsoft 365. Apache Axis 1.x has reached end of life, and no official fix is available for this branch. Organizations should migrate to an alternative SOAP framework or apply the available community patch.

The fourth vulnerability, CVE-2026-90817 (CVSS score 9.8), affects Vanderbilt University's Research Electronic Data Capture (REDCap) platform and is classified as a code injection flaw. Attackers can exploit it through specially crafted HTTP requests that reach an unintended controller route and manipulate file paths or streams during data import operations. Exploitation requires knowledge of a valid public survey hash. Safe Security observed an unknown threat actor exploiting the vulnerability to deploy a temporary web shell, followed by an in-memory loader that retrieved the XMRig cryptocurrency miner. The attackers disguised the miner as image files and the legitimate syslog-ng process, then established persistence through scheduled tasks and an additional SSH key.

CISA has set remediation deadlines for federal agencies, requiring them to address the Synology, LiteLLM, Apache Axis and REDCap vulnerabilities by November 21 or December 2, 2026, depending on the flaw. The active exploitation reports underline the need for organizations to identify exposed systems, apply available fixes or mitigations, and investigate possible signs of compromise.

与什么工作有关：老旧中间件与网络存储的暴露面管理。值得带走什么：Axis 1.x 已停产、无官方修复——这类藏在集成里的老框架不能只等补丁，须按服务清查、迁移或打社区补丁；攻击者得手后不只拿服务器，还拿凭证、VPN 配置与私钥，并用盗来的服务账号登录 Microsoft 365，说明一次边界突破会顺着凭证链走很远；Synology 缺陷已被用于部署 C3RB3R 勒索软件，NAS 不只是存储设备，也是勒索目标。什么条件下适用：组织仍有 Apache Axis 1.x 集成（特别是 Confluence Data Center 启用远程 API）或对外暴露 Synology NAS 管理界面的情况；先清查暴露面与版本，再按期限排期。
