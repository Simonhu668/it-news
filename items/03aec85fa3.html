微软不给 Copilot 一个版本号，只给日期。目前最新的 Microsoft 365 Copilot 发布说明条目是 2026 年 11 月 17 日，覆盖 11 月 3 日至 17 日的更新；同一天也是 Microsoft Ignite 2026 开幕日。发布说明称，Copilot 功能采用安全部署模型，先到达租户内一部分用户，再推广到全部用户——发布说明上的日期只表示推送已开始，不保证每位用户都已看到功能。Office 应用仍有版本号：2611 版本即 11 月 17 日版本，修复了 PowerPoint PDF 链接与访客用户敏感度标签强制问题。

11 月 17 日更新以智能体、数据连接器与管理员控制为主： - 工作流智能体节点（Copilot Studio，网页版）：一个节点可推理数据、调用工具并返回结果，微软称这取代了过去需要多个工作流步骤与人工交接的工作。 - Tableau Copilot 连接器：用户可用自然语言询问 Tableau 仪表板与可视化内容；可访问内容的权限仍由 Tableau 自身执行，连接器不会放宽可见范围。 - Outlook 内自定义引擎智能体：自定义引擎智能体现可在 Outlook 内运行，用户无需另开工具；微软称在 Outlook 的受信环境内运行更安全。 - Teams 语音档案：语音档案支持语音隔离、说话人识别、会议室识别与文字记录，并改进 Microsoft 365 Copilot 的会议回顾与洞察；组织还可自定义会议录制或转录时的提示文案，微软建议法务先审阅文案再修改。 - 自定义组织属性：管理员可把 Microsoft 365 组织数据服务中的选定自定义属性分享到 Microsoft 365 人员存储；该设置默认关闭，一旦分享，租户内所有用户与访客均可见，开启前须慎重。 - 智能体用量报告（11 月 4 日条目）：管理中心新增报告，覆盖持许可与未持许可用户的智能体使用情况，按发布者类型（用户创建、组织自建、微软、合作伙伴）细分。 - 新 Outlook 账号选择器（11 月 4 日条目）：拥有多个启用 Copilot 的账号的用户可在 Copilot 侧窗格的日历中切换账号。

11 月 4 日条目还包括：Excel 可跳转到 Copilot 修改过的单元格；Edge 新增 Copilot 新标签页；Copilot Cowork 可使用本地 Edge 浏览器（凭据、Cookie 与会话令牌保留在设备上），智能体借用已登录的浏览器会话工作，管理员应在推广前评估风险；Researcher 新增 HubSpot 连接器；PowerPoint 可参照所附演示文稿的样式新建演示文稿。

须区分 Ignite 发布与发布说明：Ignite 介绍了 Copilot Workspaces、Autopilot（长期运行智能体）、Copilot Code、Office in Copilot 与 Today 等方向，以及 Salesforce in Copilot 预览插件；但发布说明只记录已开始推送的内容，规划应以发布说明为准。微软路线图另称，Microsoft 365 Copilot 的模型选择扩展到 Claude Opus 4.8，Microsoft 365 E7 与 Agent 365 已于 11 月 17 日全面上市。

获取最新功能的实际做法：保持 Copilot 应用与 Microsoft 365 Apps 为当前版本；功能未出现通常表示尚未推送到租户，而非故障；可对部分用户启用定向发布以提前体验；Tableau 连接器、自定义属性分享与语音相关功能均须管理员配置或选择启用；推广前先复核风险设置——自定义属性的访客可见性、录制提示文案、哪些用户可用 Cowork 的本地 Edge 浏览。

原文

If you ask Microsoft for the "latest Copilot version", it won't give you a number. It gives you a date. The Microsoft 365 Copilot release notes now start with a November 17, 2026 entry, covering updates released between November 03, 2026, and November 17, 2026. That date was also the first day of Microsoft Ignite 2026. Copilot features use a safe deployment model, reaching a subset of users in a tenant first and then the rest of the organization. A date in the notes means rollout has started; it doesn't promise that every user has the feature yet. The Office apps carry numbered versions too: Version 2611 is the November 17 build, which fixed PowerPoint PDF links and sensitivity-label enforcement for guest users.

The November 17 notes deal mostly with agents, data connectors and admin controls. The notes add an agent node for workflows, listed for the web. The node can reason over data, call tools and return a response in one step. Microsoft says this replaces work that used to take several workflow steps and manual handoffs.

Microsoft Copilot now supports a Tableau Copilot connector. Users can ask questions about Tableau dashboards and visualizations in plain language. Microsoft says access to connected content still depends on the permissions Tableau itself enforces. The connector doesn't widen who can see what.

Custom engine agents now run inside Outlook, so users no longer need a separate tool to reach them. Microsoft also says running agents inside Outlook's trusted environment improves security.

The release notes confirm that voice profiles are in this update: a profile supports voice isolation, speaker recognition, identification in meeting rooms and transcripts, and enhanced meeting recaps and insights from Microsoft 365 Copilot. Organizations can also customize the notices shown when a meeting is recorded or transcribed. Microsoft says the reason is wording that fits internal policies, compliance requirements, or user guidance-style needs. Legal teams should review that wording before anyone changes it.

Admin-side changes: custom organizational attributes — admins can now share selected custom attributes from Microsoft 365 Organizational Data Service with the Microsoft 365 people store. Microsoft says the setting is off by default. Once a custom attribute is shared, all users in the tenant can see it, and so can guests. An agents usage report (November 4 entry) in the Microsoft 365 admin center covers agent use by licensed and unlicensed users, broken down by publisher type: user-created, built by your organization, built by Microsoft, or built by partners. An account selector in new Outlook (November 4 entry) lets users with more than one Copilot-enabled account see which account Copilot is acting for in Calendar.

The November 4 entry also lists: Excel can jump to the cells Copilot changed; Edge got a Copilot New Tab Page; Copilot Cowork can use a local Edge browser, with credentials, cookies and session tokens staying on the device; Researcher gained a HubSpot connector; PowerPoint can reference an attached deck's style when creating a new presentation. Cowork using the local Edge browser deserves a risk assessment: an agent working with a full signed-in browser session needs the same care as someone borrowing an unlocked laptop. Admins should know which users have it enabled, and why, before it reaches finance staff with banking portals open.

Ignite announcements and release-note entries are different things. Microsoft's Ignite announcement lists Copilot Workspaces, Autopilot (a long-running agent), Copilot Code, Office in Copilot and a feature called Today, plus Salesforce in Copilot as a preview plugin with more than 38 prebuilt sales skills. Microsoft's roadmap says Microsoft 365 Copilot expands model choice to Claude Opus 4.8, and that Microsoft 365 E7 and Agent 365 became generally available as of November 17. Ignite shows where Copilot is going. The release notes show what has actually started rolling out. Plan around the release notes.

In practice: update the clients and keep Microsoft 365 Apps on a current channel build; check whether the tenant has the feature, since rollouts are gradual; use targeted release for early testers; configure what needs configuring — the Tableau connector, custom attribute sharing and voice-related features all require admin setup or opt-in; and review the risky settings — guest visibility for custom attributes, the wording of recording notices, and who can use Cowork with local Edge — before enabling them widely.
