EBS 快捷键速查：键盘代替鼠标

Oracle EBS 表单操作的完整快捷键。打开方式：帮助菜单 → 键盘帮助，或直接按 Ctrl+K。键位以各自 EBS 环境的帮助菜单为准，不同版本个别键可能有差异。
先学这 5 个（每天排错都用得上）
Ctrl+LF11Ctrl+F11Ctrl+SShift+F1

查询5 个

F11
进入查询Enter Query
表单变成"可输查询条件"状态。用户说"找不到那张单"，让他 F11，在单号栏输入单号，再 Ctrl+F11。
Ctrl+F11
执行查询Execute Query
配合 F11 把结果查出来。查询前记得先 F7 清掉旧条件。
F12
只计数不查明细Count Query
先判断"这次查询会回来多少条"。用户说"查半天没结果"，先 F12 看量级；数据核对时快速验证"应该有 N 条"。
F7
清空当前块Clear Block
取消查询条件或块内录入。查完一轮想换条件，先 F7 清掉旧的再 F11。
Ctrl+L
值列表List of Values
在当前字段上打开可选值清单。输代码前先 Ctrl+L 看一眼有哪些合法值，比输错了再改快得多。

录入与保存9 个

Ctrl+S
保存提交Commit
任何录入或修改后按它。注意：直接点窗口 X 关闭是不保存的，修改会丢。
Ctrl+↓
新增记录Insert Record
在多行块里加一条空记录，不用去点工具栏的"+"。
Ctrl+↑
删除当前记录Delete Record
删错行的订单行、申请行。有些交易有业务校验不让删，会直接报错。
F5
清空当前字段Clear Field
输错一个字段，一键清空，不用按着 Backspace 删半天。
F6
清空当前记录Clear Record
新增一行输到一半发现选错行了，F6 整行重来。
F8
清空整个表单Clear Form
回滚所有未保存的修改，回到刚打开的状态。表单改乱了又不想保存时用——按之前先确认，未保存的东西会丢。
Shift+F5
复制上一条的字段值Duplicate Field
连续录入多行、某个字段值相同（如同一成本中心），一下复制，不用重敲。
Shift+F6
复制上一条整行Duplicate Record
新增一行和上一行大部分相同（如订单多行），复制后只改差异字段。
Ctrl+E
字段编辑器Edit
长文本（说明、备注）在小框里看不清，打开大文本框编辑。

导航8 个

Tab
下一个字段Next Field
顺序跳到下一个可输入字段。配合 Shift+Tab 往回跳。
Shift+Tab
上一个字段Previous Field
回到上一个字段改刚输错的值。
↓
下一条记录Next Record
在多行块里逐条下翻核对数据。
↑
上一条记录Previous Record
逐条上翻核对。
Shift+F8
下一批记录Next Set of Records
查询结果太多一屏看不完，往后翻页。
Shift+PageUp
上一个块Previous Block
块之间跳转（订单行回到订单头），不用鼠标点。
Shift+PageDown
下一个块Next Block
订单头输完跳到订单行继续输。
PageUp / PageDown
块内上下滚动Scroll Up / Scroll Down
行太多时滚动查看，不改变当前记录位置。

查看与帮助6 个

Shift+Ctrl+F8
动作值列表Actions LOV
打开当前字段的可选动作。字段旁没有图标但你想看有哪些可选时用。
F1
本表单可跑的报表Blitz Report List
用户问"这个界面能出什么报表"，F1 直接看清单，不用去翻菜单。
Ctrl+B
块菜单Block Menu
弹出当前块的操作菜单。不记得某个块级操作在哪，Ctrl+B 直接看。
Shift+F1
显示完整报错Display Error
状态栏一闪而过的报错没看清，用它把完整信息调出来。排错时让用户把这个完整文本发你。
Ctrl+P
打印Print
打印当前报表或界面。
Ctrl+K
快捷键帮助Show Keys
打开快捷键对照表（就是这份清单的来源）。忘了键位时现查。
练习建议：先死磕"先学这 5 个"。练法——打开销售订单：F11 输单号 → Ctrl+F11 查出来 → F12 看计数 → 改个备注 Ctrl+S 保存 → 故意输错个字段 Shift+F1 看报错，5 分钟一轮。录入那几个（Shift+F5 / Shift+F6 / F5 / F6）下次集中录数据时练。
