这一版照飞书文档的样子做：左边是可收缩的目录树——分类、模块、条目三层，点标题旁的箭头逐级收起，整个侧栏也能一键收起；右边是干净的文档阅读区，点左边的条目，正文就在右边打开，不跳页、不翻卡片墙。

怎么评审：① 点几个分类和模块旁的箭头，试试收起/展开；② 点右上角「收起目录」，看正文变宽后的阅读感；③ 在目录上方的搜索框输「公式」「附件」，看过滤是否顺手；④ 用文末的上一篇/下一篇连续读几条，感受是不是比卡片墙更像查文档。

落到 SharePoint 时怎么对应：两级目录（分类→模块）和每条一个页面的结构不变；SharePoint 原生没有飞书这种可收缩目录树，最接近的做法是建一个「目录页」：左侧用站点导航或分组视图模拟目录，右侧打开页面正文——视觉可以做到八成像，这一版 Demo 是先把阅读体验定下来，租户里再按这个目标去搭。

EBS：查错了不用慌，按 Esc 就能取消这次查询，回到原来的画面

SHSimon Hu·2026-11-05Oracle EBS查询与筛选

进了查询模式（F11）才发现条件填错了，或者突然不想查了——不用执行再退出，直接取消就行：

  1. 在查询模式下（光标所在的字段是黄色底、可输入状态），直接按 Esc 键。
  2. 系统会取消这次查询，表单回到查询前的正常浏览状态，之前的数据原样不动。
  3. 如果已经按了 Ctrl+F11 执行出结果了，Esc 就取消不了——这时按 F11 重新进查询模式改条件再查。
  4. 记住这对组合：F11 进查询、Ctrl+F11 执行、Esc 取消，查单据时就不会被"卡住"。

English — EBS: Made a wrong query? Press Esc to cancel it and return to where you were

  1. While you are in query mode (after F11, when the fields are ready for input), simply press Esc.
  2. The query is cancelled and the form returns to its normal view — your previous data is untouched.
  3. If you have already pressed Ctrl+F11 and the results are showing, Esc can no longer cancel it — press F11 again to re-enter query mode and change your criteria.
  4. Remember the trio: F11 to enter query mode, Ctrl+F11 to run it, Esc to cancel it — you will never get stuck while searching.
Oracle EBS / 查询与筛选

EBS：查询条件留空就是"不限"，只填你知道的那几项就行

SHSimon Hu·2026-11-04Oracle EBS查询与筛选

很多人查单据时觉得每个格子都得填，其实不用——空着的字段系统就当作不限制，这样查得更快：

  1. 在要查的表单里按 F11 进入查询模式。
  2. 只填你确定的条件，比如单据号、供应商名或日期，拿不准的字段直接留空。
  3. 按 Ctrl+F11 执行查询，系统只按你填了的条件筛选。
  4. 结果太多时再按 F11 补一个条件收紧范围；结果太少时反过来，把某个条件清空再查一次。

English — EBS: Leave a query field blank and it means "no limit" — fill in only what you know

  1. In the form, press F11 to enter query mode.
  2. Fill in only the criteria you are sure about, such as the document number, supplier name, or date, and leave the fields you are unsure about blank.
  3. Press Ctrl+F11 to run the query — the system filters only on the fields you filled in.
  4. If there are too many results, press F11 again and add one more criterion to narrow it down; if there are too few, clear one criterion and run it again.

*3. Press Ctrl+F11 to run the query — results are limited to your range*
*4. Tip: match the date format your system uses (copy the style you see on existing records)*

Oracle EBS / 表单录入与维护

EBS：多行录入时按 F4 复制上一行，不用重复敲相同内容

SHSimon Hu·2026-10-31Oracle EBS表单录入与维护

在 EBS 表单里录多行数据（比如订单行、分配行），很多字段和上一行一样，不用逐个重敲：

  1. 先把光标停在要新增的那一行（通常是最后一行的下一行空白行）。
  2. 按 F4，系统会自动把上一行记录的内容复制到当前行。
  3. 只改本行不一样的几个字段（比如数量、日期），其他相同字段不用动。

English — EBS: Press F4 to duplicate the previous row when entering multiple lines

  1. In a multi-line EBS form (such as order lines or allocation lines), place the cursor on the new blank row you want to add.
  2. Press F4 — the system copies the previous row's contents into the current row.
  3. Change only the fields that differ on this row (such as quantity or date); leave the identical fields as they are.
  4. Double-check the copied values, then press Ctrl+S to save.
