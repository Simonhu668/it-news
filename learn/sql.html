SQL 小课日志（去重用：课号 + 知识点 + 查询）

第 0 课（2026-10-20）· EBS 自查三件套

  • 知识点：三条只读自查查询，认识自己的 EBS 环境（版本 / 补丁 / 职责）
  • 查询 1（查版本）：SELECT release_name FROM apps.fnd_product_groups;
  • 查询 2（查补丁）：SELECT patch_name, creation_date FROM (SELECT patch_name, creation_date FROM ad_applied_patches ORDER BY creation_date DESC) WHERE ROWNUM <= 5;
  • 查询 3（查职责）：SELECT r.responsibility_name FROM fnd_user u, fnd_user_resp_groups g, fnd_responsibility_tl r WHERE u.user_name = USER AND u.user_id = g.user_id AND g.responsibility_id = r.responsibility_id AND r.language = USERENV('LANG') AND SYSDATE BETWEEN g.start_date AND NVL(g.end_date, SYSDATE);

第 1 课（2026-10-23）· WHERE 过滤

  • 知识点：WHERE 给查询加过滤条件，只留下满足条件的行；字符串用单引号，且区分大小写
  • 查询：SELECT user_name, description FROM fnd_user WHERE user_name = 'SYSADMIN';
  • 练习：把 'SYSADMIN' 换成自己的登录名（或 USER() 查到的当前用户），看返回几行

第 2 课（2026-10-27）· JOIN 多表连接

  • 知识点：JOIN 按匹配的键把两张表拼成一张结果；ON 后面写两张表相等的字段，一行对不上就不会出现在结果里
  • 查询：SELECT u.user_name, r.responsibility_name, g.start_date FROM fnd_user u JOIN fnd_user_resp_groups g ON u.user_id = g.user_id JOIN fnd_responsibility_tl r ON g.responsibility_id = r.responsibility_id WHERE u.user_name = USER AND r.language = USERENV('LANG') AND SYSDATE BETWEEN g.start_date AND NVL(g.end_date, SYSDATE);
  • 练习：数一数返回几行，对照 EBS 登录后可选的职责数量是否一致，贴结果或截图
