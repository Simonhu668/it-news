EBS 程序短码速查：见码猜意

Oracle EBS（现 Oracle ERP）并发程序短码的浓缩风格：模块前缀 + 业务动作缩写 + 对象缩写。早期系统字段长度有限，程序员习惯把英文单词砍头去尾拼在一起。学会拆解，不用死记硬背。

拆解三步法

1. 看前缀定模块前 2–3 个字母几乎总是模块：WI 生产、INV 库存、PO 采购、GL 总账、RA 应收。前缀对了，用途就猜对一半。
2. 辅音串里塞元音，还原动词MST→Master、DEPR→Depreciation、PUR→Purge、BG→Background。去元音是核心技巧。
3. 看后缀判角色MST 主程序、BG 后台进程、TP 事务处理器、PDF/RTF 报表输出。带 BG/TP 的多是"系统在背后默默干活"的，出问题先查它们跑没跑。

经典短码拆解

WIPDJMDiscrete Job Mass Load - 离散工单批量加载
  • WIWork In Process（WIP 生产模块）
  • DJDiscrete Jobs（离散工单）
  • MMass（批量导入或处理）
生产模块的离散工单批量加载程序。
WIPPURWIP Purge - 生产历史数据清理
  • WIWork In Process（WIP 生产模块）
  • PURPurge（清理、清除）
生产模块的历史数据清理程序。
WICDOL创建离散/最终装配工单
  • WIWork In Process（WIP 生产模块）
  • CCreate（创建）
  • DODiscrete Orders（离散工单）
  • LLine / Load（按订单行或成批加载）
WI（生产）+ C（创建）+ DO（离散工单）= 创建离散工单的程序。
WICDCL关闭离散工单
  • WIWork In Process（WIP 生产模块）
  • CDClose Discrete（关闭离散）
  • CLClose（关闭）
关闭离散工单的程序。
OEOIOrder Import - 销售订单导入
  • OEOrder Entry（订单管理模块的早期旧称）
  • OIOrder Import（订单导入）
订单模块的订单导入接口程序。
INCOINItem Import - 物料导入
  • INInventory（库存模块，早期短前缀）
  • COIN不是缩写，是"硬币"——物料就是钱，导入物料 = 往系统里塞钱
物料导不进来时，IT 支持第一个查的就是它。
RVCTPReceiving Transaction Processor - 接收事务处理
  • RVCReceiving（接收，砍元音留骨架）
  • TPTransaction Processor（事务处理器）
采购收货入库的后台处理器。仓库说"收了货系统没库存"，十有八九是它卡住了。
RAXMSTAutoInvoice Master Program - 应收自动开票主程序
  • RAReceivables Application（应收模块内部前缀，所以 AR 的程序很多是 RA 开头）
  • MSTMaster（主程序，去元音截断）
把订单/发运数据批量转成发票的主程序，通常还带一个子程序配合跑。
FNDWFBGWorkflow Background Process - 工作流后台进程
  • FNDFoundation（应用基础层，全系统通用）
  • WFWorkflow（工作流）
  • BGBackground（后台）
审批流卡住、通知发不出去，先看这个进程有没有在跑——EBS 排障的头号熟面孔。
GLPPOSPosting - 总账过账
  • GLGeneral Ledger（总账）
  • POSPosting（过账，截前三字母）
财务月结把日记账过到余额，就靠它；月结慢、过账报错都是查它。
POXPOPDFPrinted Purchase Order Report - 采购订单打印
  • POPurchase Order（采购）
  • POPurchase Order（打印对象）
  • PDF输出格式就是 PDF
结尾带 PDF/RTF 的，基本都是"生成某种格式文件"的报表程序——这个规律跨模块通用。
FADEPRDepreciation Run - 折旧运行
  • FAFixed Assets（固定资产）
  • DEPRDepreciation（折旧，去元音）
固定资产月结跑折旧的程序。
