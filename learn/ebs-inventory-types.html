EBS 库存交易类型速查：22 个中英对照

Oracle EBS 库存模块的标准交易类型（Transaction Type）。在库存交易查询里看到一串英文类型名，先在这里对上中文和业务场景：这笔交易是出库、入库，还是组织之间在搬。按业务流分五组，一次列全。
先拆缩写：名字里反复出现的 5 个短词
Int = Internal 内部Intr = Intransit 在途Rcpt = Receipt 接收Xfer = Transfer 转移Org = Organization 组织

生产（WIP）4 个

出库WIP Issue
生产发料
生产工单领用原材料：物料从子库存发出，计入工单消耗。
入库WIP Return
生产退料
工单没用完的物料退回子库存，是发料的逆操作。
入库WIP Completion
完工入库
工单完工，成品从工单接收回子库存。
出库WIP Completion Return
完工退回
已完工入库的成品退回工单，是完工入库的逆操作。

销售与退货3 个

转移Sales Order Pick
销售订单挑库
发运前挑库：把物料从存储子库存移到暂存子库存，等发运确认。
出库Sales Order Issue
销售订单发货出库
销售订单发运确认时产生，物料正式出库、库存减少。
入库RMA Receipt
客户退货接收
客户退货（RMA）到达后接收回库存。

采购2 个

入库PO Receipt
采购接收
采购订单到货接收，物料进入接收流程。
出库Return to Vendor
退货给供应商
已接收的物料退回供应商（RTV）。

内部订单 / 内部请购5 个

转移Internal Order Pick
内部订单挑库
内部订单发运前挑库：物料先移入暂存子库存。
发运Int Order Intr Ship
内部订单在途发运
内部订单发运：物料离开来源组织、进入在途，目标组织收货后销在途。
发运Int Order Direct Ship
内部订单直接组织间发运
内部订单直接从来源组织发到目标组织，不走在途库存。
入库Int Req Intr Rcpt
内部请购在途接收
内部请购的在途物料到达目标组织，接收销在途。
入库Int Req Direct Org Xfer
内部请购直接组织间接收
内部请购通过组织间直接转移到达目标组织并接收，不经在途。

库存内部调拨与杂项8 个

转移Subinventory Transfer
子库存转移
同一组织内，物料在子库存之间调拨，总量不变。
转移Direct Org Transfer
组织间直接转移
两个组织之间直接转移物料，不走在途，一步到位。
转移Move Order Transfer
搬运单转移
按搬运单（Move Order）把物料从源子库存移到目标子库存。
出库Miscellaneous Issue
杂项出库
不挂单据的手工出库：盘亏调整、无工单领用等都走它。
入库Miscellaneous Receipt
杂项入库
不挂单据的手工入库：盘盈调整等走它。和杂项出库是一对。
出库Account Alias Issue
账户别名出库
以账户别名作为出库去向，费用归集到别名对应的账户。
入库Account Alias Receipt
账户别名入库
以账户别名作为入库来源的杂项入库。
拆包Container Unpack
容器拆包
把容器（LPN）里的物料拆出来，改按散件管理。
读法：先看方向再看单据——Issue 是出、Receipt/Return/Completion 多为入、Transfer/Pick 是搬位置不改变总量；名字带 Intr（在途）的，都是"发运、收货"两笔成对出现，只看到一笔，就是在途还没销。注：Int Req Direct Org Xfer 字面是"直接组织间转移"，本页中文按接收方视角译作"接收"。
