EBS 库存交易类型速查

帮助看懂库存事务记录（Material Transactions）里的英文事务类型：先给日常最常见的 22 个（带一句话说明和常见来源单据），再给 EBS 常见标准事务类型的完整 47 个，外加事务来源类型 13 个、事务动作 17 个。英文是 Oracle 原文；中文为翻译草稿，不是 Oracle 官方中文，用词待确认。库存方向从本组织看：入库 = 增加，出库 = 减少，库内转移 = 同组织内换位置、总量不变，组织间转移 = 从一个组织到另一个组织。
先拆缩写：名字里反复出现的 5 个短词
Int = Internal 内部Intr = Intransit 在途Rcpt = Receipt 接收Xfer = Transfer 转移Org = Organization 组织

生产（WIP）4 个

出库WIP Issue
生产发料
把物料从仓库发到生产工单，供生产消耗。
常见来源单据：离散工单（WIP）
入库WIP Return
生产退料
发给工单但没用完的物料退回仓库。
常见来源单据：离散工单（WIP）
入库WIP Completion
完工入库
工单完工的成品或半成品入库。
常见来源单据：离散工单（WIP）
出库（退回工单）WIP Completion Return
完工退回
已完工入库的产品退回工单。
常见来源单据：离散工单（WIP）

销售与退货3 个

库内转移Sales Order Pick
销售订单挑库
发货前把货从存储子库存挑到发运暂存区，货还在本组织。
常见来源单据：销售订单（挑库）
出库Sales order issue
销售订单发货出库
发运确认后货物离开本组织，库存减少。
常见来源单据：销售订单（发运确认）
入库RMA Receipt
客户退货接收
按退货授权（RMA）接收客户退回的货物。
常见来源单据：退货订单（RMA）

采购2 个

入库PO Receipt
采购接收
按采购订单收货入库。
常见来源单据：采购订单
出库Return to Vendor
退货给供应商
已接收的物料退回供应商。
常见来源单据：采购订单

内部订单 / 内部请购5 个

库内转移Internal Order Pick
内部订单挑库
公司内部调拨订单发货前，挑库到暂存区。
常见来源单据：内部销售订单
出库（进入在途）Int Order Intr Ship
内部订单在途发运
发货组织发出内部调拨货物，货物进入在途。
常见来源单据：内部销售订单
出库Int Order Direct Ship
内部订单直接组织间发运
不经在途、直接从发货组织转出的内部调拨（发货方一侧）。
常见来源单据：内部销售订单
入库Int Req Intr Rcpt
内部请购在途接收
收货组织接收经在途运来的内部调拨货物。
常见来源单据：内部请购单
入库Int Req Direct Org Xfer
内部请购直接组织间接收
不经在途、直接进入收货组织的内部调拨（收货方一侧）。
常见来源单据：内部请购单

库存内部调拨与杂项8 个

库内转移Subinventory Transfer
子库存转移
同一组织内从一个子库存/库位移到另一个，总量不变。
常见来源单据：手工转移
组织间转移Direct Org Transfer
组织间直接转移
不走内部订单，手工把库存直接从一个组织转到另一个组织。
常见来源单据：手工
库内转移Move Order Transfer
搬运单转移
按搬运单在组织内移库（如补货）。
常见来源单据：搬运单
出库Miscellaneous issue
杂项出库
不对应业务单据的手工出库（如报废、样品、领用），计入指定科目。
常见来源单据：手工（杂项事务）
入库Miscellaneous receipt
杂项入库
不对应业务单据的手工入库（如盘盈、样品退回）。
常见来源单据：手工（杂项事务）
出库Account alias issue
账户别名出库
用预设的“账户别名”（科目快捷码）做的杂项出库。
常见来源单据：手工（账户别名）
入库Account alias receipt
账户别名入库
用账户别名做的杂项入库。
常见来源单据：手工（账户别名）
数量不变Container Unpack
容器拆包
把物料从 LPN/容器中拆出，库存总量不变。
常见来源单据：LPN/容器

想要完整清单时

本页的标准类型按 EBS 标准知识整理，名称拼写可能与实际系统略有差异；各系统如有自定义事务类型，这里不会包含。要拿到某个系统里的全部事务类型（含编号、自定义类型、停用日期），可以把下面这条只读 SQL 交 IT 评审后在本地执行（只有 SELECT，无任何修改操作）：
只读 SQL：导出全部库存事务类型 
-- 导出系统里全部库存事务类型（含自定义类型、停用日期）
-- 只读 SELECT，无 DDL/DML；评审后在本地用 SQLcl 执行
SET SQLFORMAT csv
SET FEEDBACK OFF
SPOOL transaction_type_meanings_YYYYMMDD.csv

SELECT mtt.TRANSACTION_TYPE_ID,
       mtt.TRANSACTION_TYPE_NAME,
       mtt.DESCRIPTION,
       mtt.TRANSACTION_SOURCE_TYPE_ID,
       mtst.TRANSACTION_SOURCE_TYPE_NAME,
       mtt.TRANSACTION_ACTION_ID,
       ml.MEANING AS TRANSACTION_ACTION_MEANING,
       mtt.USER_DEFINED_FLAG,
       mtt.DISABLE_DATE
  FROM MTL_TRANSACTION_TYPES mtt
  LEFT JOIN MTL_TXN_SOURCE_TYPES mtst
    ON mtst.TRANSACTION_SOURCE_TYPE_ID = mtt.TRANSACTION_SOURCE_TYPE_ID
  LEFT JOIN MFG_LOOKUPS ml
    ON ml.LOOKUP_TYPE = 'MTL_TRANSACTION_ACTION'
   AND ml.LOOKUP_CODE = mtt.TRANSACTION_ACTION_ID
 ORDER BY mtt.TRANSACTION_TYPE_ID
;

SPOOL OFF
EXIT
读法：先看方向再看单据——Issue 是出、Receipt / Return / Completion 多为入、Transfer / Pick 是搬位置不改变总量；名字带 Intr（在途）的，都是"发运、收货"两笔成对出现，只看到一笔，就是在途还没销。注：Int Req Direct Org Xfer 字面是"直接组织间转移"，本页中文按接收方视角译作"接收"。
